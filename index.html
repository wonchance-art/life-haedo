☁ 온라인 DB 동기화
Supabase(무료) 프로젝트의 URL과 anon 키를 넣으면 모든 문서가 자동 동기화된다. 로컬 저장은 그대로 유지(오프라인 안전).
최초 1회 — Supabase SQL Editor에 실행할 생성문 
create table if not exists charts (
  id text primary key,
  name text,
  data jsonb,
  updated_at timestamptz,
  user_id uuid default auth.uid()
);
alter table charts enable row level security;
drop policy if exists "own" on charts;
drop policy if exists "personal" on charts;
create policy "personal" on charts
  for all using (true) with check (true);
개인용 개방 정책 — 키를 아는 사람은 접근 가능. 아래 계정 로그인(선택)을 쓰기 시작하면 정책을 계정 분리형으로 올릴 수 있다.
