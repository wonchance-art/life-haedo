# 뉴스 · 읽기 피드 개편

2026-10-21. Mode: Read, with short Operate controls. Scope: `assets/life/discovery.css` and the parent-owned news DOM. Product truth, storage and ranking are unchanged.

## 방향

앱의 흰 한 열·틸·Pretendard와 공통 탐색은 유지하고 뉴스의 정보 순서를 교체한다. 피드 / 좋아요 / 담기 세 목적지를 최상단 전체폭 밑줄 탭으로 만든다. 그 아래 주제·출처 / 언어 옵션 / 추천·기록을 한 줄의 native details로 모으고, 펼친 설정은 전체 열을 쓴다. 다음에 짧은 정렬과 목록 갱신만 둔다.

기사는 실제 출처의 문자 이니셜·이름·날짜 → 강한 제목 원문 링크 → 실제 제공된 요약이 있을 때만 요약 → 좋아요·담기·명시 번역의 행동 행으로 읽는다. 글 옵션에 자료 보관·읽음·관련 없음·근거 제외·완전 삭제를 모으고, 확보 범위·날짜의 한계·검색 근거는 기사 정보에 둔다. 기사와 기사는 구분선과 여백으로 나누며 가짜 로고·사진·요약·사회적 반응 수를 추가하지 않는다.

## 보존할 기준

- 좋아요와 담기는 독립된 명시 행동이다. 틸 선택 상태와 아이콘+문자를 함께 사용한다.
- 제목이 원문 읽기의 주 진입이다. 번역은 확인된 설정과 클릭 때만 기존 링크를 사용한다.
- 메뉴·입력은 기존 DOM과 native details/checkbox/select를 유지한다. `[hidden]`을 CSS로 되살리지 않는다.
- 모바일은 350px 본문에서 긴 한국어/영어 제목과 출처를 줄바꿈한다. 입력 16px·조작 44px·키보드 초점 테두리를 유지한다.
- 출처의 실패·오래된 목록·본문 미확보를 숨기거나 최신 수집 성공으로 표현하지 않는다. 상태는 축약된 footer/기사 정보에서 확인한다.
- 접힌 읽기 비교와 사본·복구·실패 입력은 그대로 유지한다. 개인 추천을 기본 켜거나 새 판정을 생성하지 않는다.

## 검수와 한계

기존 390px 첫 기사 제목은 y591.78, 820/1440px은 y588.03에 나타났다. 기존 화면의 설정·설명과 반복된 행동이 같은 무게로 놓인 것이 읽기 진입을 늦췄다. 같은 공개 피드와 익명 계정으로 변경 전후 390/820/1440px을 독립 검수한다. 기사·반응·더보기·설정·실패 복구를 함께 확인하고, 실제 결함은 한 번에 보완한 뒤 확인한다. 실제 사용자 독서 유용성·Apple 기기·Google 번역 결과의 증거로 사용하지 않는다.

1차 구현 검수: `.local/news-social-redesign-20261021/after/news-after-{fresh,more,language,preferences}-{390,820,1440}.png` 12장을 직접 열람했다. 첫 기사 제목은 390px y380.75, 820/1440px y392.75로 앞당겨졌다. 독립 브라우저 측정에서 가로 넘침·44px 미만 조작·대비 미달은 0건(최소 대비 5.59:1)이었고, 키보드 열기·Escape 닫기·초점 복귀도 통과했다. 펼친 설정은 본문 열을 쓰며 긴 한·영 제목, 이니셜과 출처, 기사 행동이 겹치지 않는다. 화면 밖 보존·인증·충돌 검사는 별도 기능 검증 결과로 다룬다.

마감 독립 검토에서 글 옵션을 열면 요약 버튼이 48px 아래로 이동하는 문제가 추가 확인됐다. 2차 보완은 기사 행동을 grid의 같은 첫 행에 두어 반응과 요약 버튼 위치를 유지하고, native details의 옵션 본문만 문서 흐름 안에서 아래로 확장하도록 바꿨다. 번역 링크는 별도 다음 행이며 떠 있는 메뉴·가림·음수 여백·details의 display:contents를 사용하지 않는다. 주탭의 활성 배경도 투명으로 명시해 밑줄 선택 규칙과 맞췄다. 마지막 3폭 확인에서 여닫기 좌표·44px·긴 라벨과 전체 피드를 함께 검증한다.
