# 블로그 시각 개편 — 현재 표면 계약

2026-10-18 KST. 앞선 사용 흐름 개편 다음에 요청한 **실제 앱의 시각 디자인 교체**다. 홈의 대표 글 목록·글쓰기·읽기·복귀 구조를 바탕으로, 프로필과 글의 활자 위계·한글 글꼴·색·여백·조작의 형태를 함께 바꾼다. 최종 수치의 기준은 [DESIGN.md](../DESIGN.md)와 실제 CSS이며, 구현·검증 근거는 [시각 개편 기록](../docs/design-review/blog-visual-redesign.md)에 둔다.

## 방향과 선택 근거

차분한 SNS 탐색 안에서 개인의 글을 읽는 현대적인 한국어 블로그다. 흰 읽기 면과 아주 옅은 초록 회색 캔버스, 짙은 틸 행동색, Pretendard의 분명한 제목 위계를 쓴다. 프로필 이름과 실제 글 제목이 먼저 눈에 들어오고, 전역 탐색과 반복 화면명은 그보다 작게 남긴다.

이전 화면은 기능과 목록 구조가 정돈되어 있었지만 프로필·메뉴·글 제목의 크기 차가 작고 긴 회색 작성 안내가 본문보다 먼저 보였다. 이번 변경은 글꼴과 색을 바꾸는 데 그치지 않고 소유자 이름·제목·본문의 위계와 작성 진입의 실루엣을 바꾼다. 큰 표지·장식 사진·가짜 반응 수로 빈 화면을 채우지 않는다.

## 화면별 모드와 구성

- **홈 — Read와 Operate:** 프로필 → 실제 작성 버튼 → 필요한 초안 이어쓰기 → 글/초안/보관함과 검색 → 실제 글. 프로필에는 제목에서 얻은 이니셜을 쓴다. 같은 작성자·아바타를 글마다 반복하지 않는다.
- **작성·프로필·검색·설정 — Operate:** 실제 입력과 현재 조작이 우선이다. 작성 안내는 클릭·키보드로 작성기를 여는 버튼이며 편집 가능한 입력처럼 표시하지 않는다. 저장 상태와 복구 조작을 입력 가까이에 둔다.
- **글·원문·공개 사본 — Read:** 한 열의 제목·본문·출처를 읽는다. 제목 없는 글의 실제 첫 문장을 유지하고 사진은 있는 자료에서만 보여준다. 피드는 여백과 가는 선으로 나누며 글마다 그림자 카드를 두지 않는다.
- **공개 전 화면:** 실제 로그인과 현재 제품 설명을 사용한다. 개인 글이 공개된 것처럼 보이는 가짜 사회적 지표나 사례를 추가하지 않는다.

## 조작·접근성

홈·자료실·도구·설정과 내부 ID는 유지한다. 넓은 화면의 라벨 탐색, 중간 폭의 아이콘과 짧은 라벨, 모바일 화면 끝의 하단 탐색은 같은 목적지를 연다. 현재 위치는 틸색과 `aria-current`로 함께 표시한다. 모바일 작성 중 하단 탐색은 감추고 닫은 뒤 복원한다.

일반 조작은 최소 44px, 입력은 최소 16px다. 탭의 좌우/Home/End 키·선택 표시, 숨은 검색의 라벨, 모달 Escape·초점 복귀, sticky 조작과 안전 영역의 여백을 유지한다. 한글 조합 중 입력 DOM이나 값을 다시 만들지 않는다. 초점은 실제 배경에서 확인하며 색만으로 선택·오류·공개 상태를 설명하지 않는다.

생동감은 기존 150–180ms 조작 색 변화와 짧은 아이콘 눌림에 한정한다. 본문 등장이나 읽던 구절에 모션을 추가하지 않는다. `prefers-reduced-motion`에서는 전환·애니메이션·부드러운 스크롤을 끄고, forced-colors에서도 현재 위치·초점·경계를 남긴다.

## 보존 경계와 이전 방향

비공개 저장·현재 브라우저·동기화·공개 사본·화면 숨김은 서로 다른 상태다. 시각 개편은 원문·정확 버전·UTF-16 구간·초안·사진 Blob·저장 형식·계정 격리·백업·복원을 바꾸는 권한이 아니다. 읽기·수정·프로필을 오간 뒤 탭·검색어·표시 범위·정확한 항목·초점 복귀를 보존한다. 저장 실패와 늦은 응답에 입력을 남긴다.

이 문서는 [SNS 블로그 방향](sns-blog-direction.md)과 [사용 흐름 계약](blog-journey-direction.md)의 **당시 흰색/차콜 주 행동·시스템 글꼴 등 시각 값만** 이어서 교체한다. 앞선 문서는 당시 결정의 이력이며, 원문·공개·저장·복구·탐색 계약은 계속 유효하다. 이전 라벤더·종이색·명조·떠 있는 탐색띠도 비교 이력으로 보존한다. 과거 파일을 정리하거나 역사를 다시 쓰는 작업은 이번 범위가 아니다.

## 완료 판단

1440·820·390px에서 같은 익명 한글 내용의 전후와 빈 화면·긴 제목·글쓰기·읽기·자료실·설정을 확인한다. 프로필과 글 제목의 위계, 본문 등장 위치, 가로 넘침, 조작·키보드·대비·모션 감소를 분리해서 판단한다. 기능 검사 통과를 미적 품질의 증명으로 쓰지 않는다. 브라우저 폭 모사는 실제 Mac/iPad/iPhone·IME·VoiceOver 체험과 구분하며 운영 인증·DB·공개 배포도 별도다.

Impeccable 4.5.0은 프로젝트 내부 지침으로 수동 적용한다. 설치되지 않은 context·detect·doctor·자동 hook을 실행했다고 표시하지 않는다.
