# 분류 파일과 자료실 연결 — 구현 전 계약

2026-10-18 UTC. 모드: Operate + Read. 해도는 외부 여러 곳에 흩어진 내 글을 가져와 한곳에서 찾고 관리하는 도구다. 이번 단위는 비공개 분류 JSON을 사용자가 골라 기존 자료실의 정확한 원문과 연결하는 흐름이다. 개인 분류 원문을 앱에 동봉하거나 공개 저장소에 넣지 않는다.

- **시작과 결과:** 자료실에서 파일 선택 → 검증한 범위·연결/미연결 미리보기 → 명시적 로컬 적용 → 출처·주제·형태·확인 필요 필터 → 정확 버전 읽기 → 같은 목록 복귀. 새로고침·별도 분류 파일 내보내기·분류 연결 지우기까지 완결한다.
- **화면:** 기존 셸·한 열·SVG·44px 조작·16px 입력·초점·safe-area를 재사용한다. 분류 도구는 접힌 보조 조작이며 본문·기존 검색을 밀어내는 큰 상시 패널이나 대시보드를 만들지 않는다. 적용 전 파일과 적용된 분류를 구별한다.
- **데이터:** `life-source-classification-v1`에 sourceCommit·taxonomy와 records의 path/sha256/isContent/source{id,label}/kind{id,label}/topicIds/primaryTopic/reviewReasons만 정규화한다. 원본 파일의 title·preview·body·저자 결론은 저장·내보내기에서 버린다. 경로와 분류 메타데이터도 비공개임을 유지한다.
- **정확성:** 원래 경로·출처 URL의 commit·실제 보관 본문 해시가 일치하는 정확 버전에만 연결한다. 최신 버전에 자동 승계하지 않고 변경·누락·다른 출처는 미연결로 남긴다. 보조·추출물은 글과 구분하고 저자·신념을 추정하지 않는다.
- **보존과 복구:** 계정·작업공간별 독립 로컬 메타데이터와 CAS를 사용한다. 일반 자료 백업·동기화·공개 사본에 섞지 않는다. 파일 선택 취소·검증 실패는 기존 적용값을 보존하고 저장 실패는 검토 후보를 남긴다. 늦은 응답·계정/공간 전환은 다른 범위에 결과를 표시하거나 적용하지 않는다. 지우기는 분류 연결만 지우며 원문·원래 태그·버전·링크는 유지한다.
- **검증:** 익명 파일로 정상/잘못된 입력·변조 해시·변경 버전·같은 경로의 다른 출처·부분 연결·보조물·저장 경합·계정 격리·필터 왕복·reload·내보내기/다시 선택·지우기를 확인한다. 기능 검사·직접 이미지 검토·실기·운영 반영을 분리해 [구현 기록](../docs/design-review/source-classification.md)에 남긴다.

네이티브 파일 API·기존 Core 해시와 저장 엔진을 재사용한다. 외부 분류 서비스·새 DB/schema/API·라이브러리·본문 재분류 엔진을 추가하지 않는다. 패키지나 공식 문서의 최신 상태를 확인하지 않은 채 조사 완료로 표시하지 않는다.
