# 뉴스 · 본문 우선 최소 조작

2026-10-21. Mode: Read. 최신 사용자 요청이 이전 뉴스의 문자 탭·설정 행·상시 설명보다 우선한다. 기존 흰 한 열·틸·Pretendard와 공통 탐색, 원문·반응·비공개 보관 계약을 유지한다.

## 화면 구성

상단은 피드·좋아요·담기의 세 SVG 버튼, native 정렬 select, 뉴스 설정 gear만 한 줄로 둔다. 아이콘은 20px, 조작 영역은 44px다. 문자 라벨과 숫자를 상시 그리지 않되 실제 행동 이름·선택 상태는 접근 가능한 이름·title·aria 상태로 유지한다. 기본 피드에는 정상 상태 설명·개수·출처 실패 목록을 반복하지 않는다. 처리 실패와 선택 보존·재시도는 필요한 순간에 남긴다.

기사는 한 줄 출처·실제 날짜, 제목 원문 링크, 실제 요약이 있을 때만 요약, 아이콘 한 줄 순서다. 출처 이니셜 배지와 제목의 외부 화살표는 제거한다. 좋아요·담기·번역·더보기는 글자 없이 같은 44px 행에 두며, 좋아요·담기의 선택은 채운 도형으로도 구분한다. 번역을 끈 경우 빈 동작을 만들지 않고 grid의 작은 빈 트랙만 남겨 더보기 좌표를 유지한다. 더보기는 기존 native details이며 열기 전후 trigger 위치를 유지하고, 기사 정보와 부가 행동만 아래 문서 흐름으로 펼친다. 기사 정보는 별도 상시 행을 차지하지 않는다.

뉴스 설정은 피드와 별도 표면이다. 돌아가기·뉴스 설정 제목 다음 기존 주제/출처·언어·개인 추천·반응 해제·읽기 비교·제외 글·출처 수집 상태·사본과 초기화를 둔다. 기존 native details와 입력 DOM을 유지하고 화면 전환에는 `[hidden]`을 우선한다. 기본 피드의 문장·도형을 줄이는 것을 저장·복구 기능 제거로 바꾸지 않는다.

## 보존·검수

새 라이브러리·팔레트·공통 CSS·저장 모델·추론을 추가하지 않는다. 정상 상태의 스크린리더 안내는 지역 `.sr-only`로 남기며 에러를 함께 숨기지 않는다. 같은 공개 피드와 익명 계정의 390/820/1440px 한 번 batch에서 상단 한 줄·기사 한 줄 조작·긴 출처/제목·뉴스 설정·더보기 trigger 좌표·44px/16px·초점·가로 넘침을 확인한다. 실제 읽기 효용·Apple 기기·Google 번역 결과는 이 검수 범위에 포함하지 않는다.

구현 후 `.local/news-minimal-20261021/after-batch1/news-{fresh,more,settings,settings-draft}-{390,820,1440}.png` 12장을 직접 열람했다. 첫 기사 제목은 390px y190, 820/1440px y200(이전380.75/392.75/392.75)으로 앞당겨졌다. 기본 화면의 기사 정보·관리 설명은 별도 줄을 차지하지 않고 긴 한·영 제목과 출처가 겹치지 않는다. 더보기는 버튼 위치를 유지한 채 기사 아래로 펼쳐진다. 독립 측정은 가로 넘침0·조작44px 이상·여닫기 좌표차0을 확인했고, 설정 닫기/재진입에서 같은 입력 노드·값을 유지했다. 이 12장은 기본 번역 끄기 상태이며 실제 번역 서비스 결과의 증거는 아니다. 시각 보완 없이 현재 CSS를 동결한다.
