# 기록 재발견

2026-10-05. 도구 → 다시 찾기 → 기준 기록 선택 → 관련 기록 최대 3개 → 원문 확인·제외·묶음 검토로 이어지는 작은 흐름이다. 직접 쓰거나 가져온 기록을 브라우저 안에서 비교한다. 외부 AI·계정 수집·외부 콘텐츠 추천·공개 전송을 추가하지 않는다.

## 근거와 한계

- 같은 주제: 발췌의 주제가 같고 두 원문 버전을 정확히 참조할 때만 사용한다.
- 같은 묶음: 해당 두 원문 버전을 함께 담은 묶음이 있을 때만 사용한다.
- 공통 단어: 제목과 본문 앞 16,000자에서 일치하는 서로 다른 단어가 2개 이상일 때 사용한다. 일반적인 단어는 제외하며 한글 조사 제거·유사어·의미 이해를 추정하지 않는다. 제목만 확보한 링크는 제목의 근거로 구별한다.

기준 기록은 선택한 버전이다. 후보는 다른 원문별 최신 보관 버전 하나이며 과거 버전의 주제·묶음 근거를 새 버전에 물려주지 않는다. 제목은 기존 스키마의 현재 제목이며 과거 제목 이력은 없다. 근거가 없으면 결과를 채우지 않는다. 저장한 글은 동의·현재 신념·성격의 증거가 아니다.

[공식 오픈소스 비교](../life-tools-design/open-source-review.md)를 거쳐 기존 정확 검색을 재사용하고 읽기 전용 근거 계산만 분리했다. 새 런타임 의존성은 없다. 같은 의미의 다른 표현을 자주 놓치는지 실제 익명 한글 사례로 확인한 뒤 형태소·의미 검색을 검토한다. 지금은 설명할 수 없는 점수보다 근거의 정확성을 우선한다.

## 보관과 복구

`life-workbench-v1`의 선택 필드 `discovery.excludedPairs`에 방향 있는 원문 ID 쌍을 최대 1,000개 저장한다. A를 기준으로 B를 제외해도 B를 기준으로 A를 찾는 데 영향을 주지 않으며 원문을 삭제하지 않는다. 같은 원문의 새 버전에도 이 제외를 유지한다. 이는 전역 분석 제외 설정이 아니다.

기존 필드만 있는 v1 구성·백업은 그대로 읽는다. 제외는 계정·작업공간별 구성 CAS 저장과 오류 재시도를 재사용하며 원문 동기화에는 포함되지 않는다. 자료·구성 백업은 제외 쌍도 포함하고 복원할 때 새 원문 ID로 일관되게 바꾼다. 기존 자료 JSON·Markdown에는 구성이 포함되지 않는다. 누락 참조를 임의의 원문과 연결하지 않는다.

묶음 담기는 기준·후보의 정확한 버전을 기존 검토 화면에 전달한다. 확인 전에는 원문이나 묶음을 바꾸지 않는다. 검색어·기준 선택은 작업공간별 현재 화면 세션에만 유지하고, 제외 설정과 달리 새로고침 후 복구를 약속하지 않는다.

## 검증

- 정적 검사: HTML 17개·JS 44개·로컬 참조 231개·PWA 셸 통과.
- Node 회귀: 276/276. 근거 계산, 구형 구성 수용, 방향 있는 제외와 백업 복원, 서비스워커 설치 실패를 포함한다.
- 재발견 브라우저: 고유 10/10, 1440·820·390px에서 관련 결과·빈 자료·무결과·초기 로딩·읽기 오류 15개 상태. 정확한 과거 기준/최신 후보, 제외 저장 실패·이동 차단·재시도, 묶음 검토 취소, 계정/작업공간 경계, 사본 ID 재매핑을 확인했다. [실행별 근거](evidence/rediscovery-report.json)
- 키보드 원문/묶음 검토 복귀 초점, Escape, 390px 터치, 합성 한글 조합을 확인했다. 작은 글자 대비 최소 6.05:1, 입력 16px 이상·조작 44px 이상·가로 넘침 없음. 실제 IME 동작 검증과 다르다.
- 기존 영역 브라우저 17/17·27개 상태, 홈/인증 탐색 13/13 통과. 이 검사는 실제 동봉 SDK·IndexedDB와 모의 Auth HTTP를 사용했고 운영 자료를 쓰지 않았다. 의도한 인증 실패 1개 외 뜻밖의 콘솔·페이지 오류는 없었다.
- 공개 산출물·v66→v67 서비스워커 갱신 9/9. 실제 이전 사본을 유지한 채 새 셸로 교체하고 오프라인·재인증을 확인했다. 의도한 네트워크/콜백 오류 2개와 실제 Google 계정 로그인은 구분한다.

root가 세 폭의 대표 이미지를 직접 검토했다. 흰 본문 피드·얇은 구분선과 기존 아이콘을 유지하고, 담기 조작에는 옅은 보라·근거에는 민트를 사용한다. 긴 한글 제목은 행 안에서 줄바꿈하며 390px 하단 도크는 스크롤 공간을 보존한다.

## 실행과 배포

로그인 후 **도구 → 다시 찾기 → 검색하거나 최근 기록에서 기준 선택 → 근거 확인 → 원문 열기/묶음 담기/제외** 순서로 체험한다. 제외한 연결은 같은 화면에서 복원한다. 라이브 반영은 PR·Pages 결과를 확인한 후 기록한다.
