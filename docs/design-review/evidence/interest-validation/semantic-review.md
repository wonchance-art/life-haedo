# MODEL-02 독립 의미 재독

판정은 **현재 동결 후보 도입 기각**이다. 후보의 근거 정확도 90%는 사전 기준 95%보다 낮고, 주제와 반복 질문 누락도 baseline보다 늘었다. 기존 baseline도 절대 도입 기준을 충족하지 못하므로 baseline을 검증된 대안으로 출시할 근거가 없다.

| 지표 | baseline | candidate | 사전 조건 |
|---|---:|---:|---:|
| 의미상 유효 근거 | 22/26 (84.6%) | 9/10 (90.0%) | ≥95% |
| 금지 양의 근거 | 3 | 1 | 0 |
| 유효 본문 2개 이상인 주제 | 5/10 | 3/10 | ≥8/10 |
| 주제별 macro evidence recall | 44% | 26% | ≥50%, baseline 이상 |
| 반복 질문 군집 recall | 2/4 (50%) | 0/4 (0%) | ≥3/4, baseline 이상 |
| 원문·SHA·UTF-16 인용 일치 | 26/26 | 10/10 | 100% |
| 장문 중간의 올바른 근거 | 0 | 0 | ≥1 |

후보의 실제 출력 인용 10개를 독립적으로 읽어 고정 평가기 판정과 일치함을 확인했다. 틀린 근거는 기술·과학에 붙인 h044의 “다음은 과거 도구 사용 안내의 인용이다.”다. 이 도입문과 원문은 과거 명령을 인용한 시험 자료이며, 기술이나 과학 관심을 뒷받침하지 않는다. 인용 명령을 실행했다는 관측은 없다. 기술·과학 표시 support=2 중 실제 유효 지지는 h004 하나다.

baseline의 오류는 인용 명령 h042를 경제 근거로 쓴 것, 부정문 h041과 인용 안내 도입문 h044를 기술·과학 근거로 쓴 것, 복습·기억 질문 h038을 독서·글쓰기 근거로 쓴 것이다. 후보는 일부 오탐을 줄였지만 출력량도 26개 근거에서 10개로 줄었으며 recall이 함께 떨어졌다.

동결 소스의 순수 텍스트 선택 함수만 메모리에서 노출해 확인했다. 원본 파일·임계값·평가기·추론 출력은 바꾸지 않았고 모델을 다시 실행하지 않았다. 유효 질문 h032의 “쓰지 않으면서”, h034의 “못 자서”, h035의 “다투지 않고”, h036의 “번지지 않도록”가 넓은 부정 표현 필터에 걸려 문장 전체가 제외됐다. 원하지 않는 상태나 갈등을 피하는 방법을 묻는 질문을 관심 부정으로 취급한 것이다. 나머지 복습 질문 쌍도 출력되지 않았지만, 개별 모델 점수 추적이 없어 그 점수 수준의 원인은 단정하지 않는다.

장문 h045는 실제 비절단 tokenizer로 4,557 tokens다. 후보에서 361개 적격 범위 중 12개를 고른 결과 관련 중간 범위는 하나도 선택되지 않았다. 두 번째 관련 문장은 “막지 않고”라는 표현으로 필터링됐고, 남아 있는 첫 관련 문장도 샘플에 들지 않았다. window 수를 늘린 사실만으로 중요한 중간 대목 보존을 보장하지 못했다.

질문 0개에 대해 고정 평가기가 기록한 precision=0은 빈 출력 계산 규약이다. 실제 오답 질문을 출력한 비율이라는 뜻은 아니다. 반복 질문 recall=0은 그와 별개로 기준에 미달한다.

후보에서 원문 인용·해시·범위 10개는 모두 맞았고 입력 bundle 불변, 본문 중복, 명시적 unknown/other→self 귀속 검사는 통과했다. 정확한 출처와 보존 성공은 의미상 올바른 관심 추출을 보장하지 않는다. 이 표본에서 명시적 귀속 오류가 없다는 것이 모든 저자·믿음 표현의 정확성을 증명하지도 않는다.

분석 시간은 같은 단일 브라우저 실행에서 baseline 약 3.03초, 후보 약 6.55초였고 최초 준비는 약 15.02초였다. 실제 사용자 기기의 성능 일반화를 뜻하지 않는다.

사전등록, fixture, 평가기, 동결 구현, baseline/candidate 출력은 결과를 보고 수정하지 않았다. 후속 개선 후보를 만들 경우 이번 held-out은 개발 사례로 사용된 자료가 되므로 새 독립 평가가 필요하다.
