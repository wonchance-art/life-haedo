# 비공개 NLI 12쌍 실제 실행 결과

판정: **후속 조사 가능성 기준 통과**. 고정 argmax 평가에서 12/12 정답이며 부정 3/3, 과거 명령 인용 3/3을 모두 맞혔다. 사전 조건인 전체 ≥10/12 및 두 범주 전부 정답을 충족했다. 현재 관심 추출 후보의 48문서 도입 기각은 그대로다.

| 범주 | 정답 |
|---|---:|
| 직접 함의·긍정 질문 바꿔 쓰기 | 4/4 |
| 명시 부정 | 3/3 |
| 인용된 과거 명령에서 개인 취향·실행을 단정하는 가설 | 3/3 |
| 알려지지 않은 사실·질문으로 알 수 없는 구매 사실 | 2/2 |

정답과 예측을 독립적으로 다시 읽었다. 과거 명령 세 쌍은 작성자의 취향이나 실제 수행을 긍정하지도 부정하지도 않으므로 neutral이 맞다. 명시 부정 세 쌍은 긍정 가설과 모순되므로 contradiction이 맞다. 질문 바꿔 쓰기 한 쌍을 포함한 네 긍정 사례는 원문에서 직접 뒷받침된다. 오답과 top-score 동점은 없었다.

입력은 prompt나 가설 template 없이 직접 premise/hypothesis text pair였다. 고정 max_length=256에서 비절단 길이는 41–72 tokens이며 12개 모두 실제 입력 길이가 같아 **절단 0개**다. runtime errors, 외부 body 요청, 가변 revision 요청은 모두 0개로 기록되었다. 이 검사는 장문을 다루지 않았다.

모델은 pinned mDeBERTa-v3 NLI ONNX q8, Transformers.js 4.3.1, WASM 1스레드였다. 최초 준비 약 49.37초, 12쌍 추론 약 3.72초, 쌍별 약 0.18–0.52초였다. 모델 메타데이터 크기는 338,341,610 bytes, 관측 JS heap은 441,121,690 bytes다. JS heap은 전체 RAM이나 peak 메모리가 아니며, 단일 브라우저 실행을 사용자 기기 성능으로 일반화하지 않는다.

12개 모두 argmax 정답이지만 확률 보정이나 확실성을 검증한 것은 아니다. 가장 작은 raw-logit 1·2위 차이는 n01의 0.1110다. 이 수치는 설명용이며 새 임계값을 적용하지 않았다.

이 결과는 **주어진 짧은 원문과 가설의 함의 관계**를 판정할 가능성을 보여 준다. 임의 자료의 주제를 발견하거나 좋은 가설을 만들고, 반복 질문을 묶고, 긴 원문의 중간 근거를 찾으며, 출처와 저자 귀속을 지키는 전체 관심 추출 흐름은 평가하지 않았다. 특히 이전 후보의 recall 하락과 장문 누락이 해결됐다는 근거가 아니다.

후속으로 조사할 가설은 후보 근거 뒤에 독립적인 NLI 검증 단계를 두는 것이다. 실제 도입을 판단하려면 가설 생성·근거 선택을 포함한 고정 파이프라인을 만들고, 이번 12쌍 및 기존 48개와 다른 새 독립 평가를 해야 한다. 작은 합성 표본 12개를 실제 사용자 자료의 정확도 추정으로 쓰지 않는다.

fixture·사전등록·평가기 해시는 봉인값과 일치한다. 정답·argmax·기준을 결과에 맞춰 수정하지 않았고 이전 48문서 산출물도 바꾸지 않았다.

runner 코드도 독립 확인했다. 브라우저에는 id/premise/hypothesis만 투영해 전달하고 expectedLabel은 전달하지 않았다. 실제 tokenizer text_pair 사용과 고정 256 한도가 확인되며 runner SHA256은 기록한 동결값과 일치한다.
