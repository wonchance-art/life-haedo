# 뉴스 본문 집중과 별도 설정

2026-10-21. 최신 사용자 요청에 따라 기본 피드의 설명·문자 반응·기사 정보 행·아래 관리 영역을 정리한다. 기준은 PR126을 포함한 main `7744aba` / SW151이며, 이번 화면은 SW152로 출시한다. [뉴스 열기](https://wonchance-art.github.io/life-haedo/index.html?section=news).

## 구현과 보존

한 줄의 피드·하트·북마크 아이콘, 정렬 선택, 뉴스 설정 뒤에 실제 출처·유효 날짜와 원문 제목·제공된 요약·아이콘 조작 한 줄만 표시한다. 반응 이름은 접근 가능한 이름과 도움말로 유지하고, 선택한 반응은 채운 도형과 aria 상태로 구분한다. 기사 정보·일치 근거·본문 확보 범위는 각 기사의 더보기 안에서 확인한다. 정상 처리 문구는 스크린리더 안내로 남기며, 빈 목록·실패·재시도는 실제 필요한 때 표시한다.

톱니로 여는 **뉴스 설정**은 피드와 별도 화면이다. 주제·출처·언어·개인 추천·읽기 비교·반응 해제 기록·제외한 글·출처와 목록 상태·사본과 초기화를 이곳에서 관리한다. 돌아가기는 화면 표시만 전환하므로 입력 DOM·한글 조합·미저장 선택·실패 입력·현재 비교를 보존한다. 외부 화면 이동의 저장/충돌 가드는 그대로 적용한다. 숨겨진 설정에 미해결 오류가 있으면 피드의 설정 확인으로 복구에 접근한다.

개인 추천은 기본 꺼짐이며 설정의 명시 체크박스로 켠다. 정렬 선택만으로 켜지지 않고, 담기·읽기 비교·미독·무응답을 좋아요로 추정하지 않는다. 기존 모델·저장 형식·백엔드·외부 라이브러리는 변경하지 않는다. 기존 [공식 오픈소스 비교](../life-tools-design/open-source-review.md)와 같은 native DOM·고정 SVG를 재사용하며, 별도 SNS 프레임워크나 외부 자산 없이 요청한 밀도를 구현한다. [화면 방향](../../.impeccable/news-minimal-direction.md).

## 검수 범위

고정 공개90글/7출처의 전후 화면과 격리된 합성 Auth·실제 SDK/IndexedDB에서 검수한다. 화면 폭·키보드·한글 조합은 자동화 모사이며 실제 Apple 기기·운영 계정·사용자 실독 효용이나 Google 번역 품질로 확대하지 않는다. 운영 수집100글/8출처와 체크인90글/7출처를 섞지 않는다.

같은 공개 자료에서 첫 기사 제목은390px y380.75→190,820·1440px y392.75→200으로 이동했다. 세 폭의 기본/더보기/설정/입력12장에서 조작44px 이상·가로 넘침0·더보기 trigger 이동0과 설정 입력 DOM/값 보존을 확인했다. 단위1200개와 정적22HTML/153JS/648참조도 통과했다. 스타일은 첫 묶음 검수 후 추가 보정 없이 동결했다.

독립 최종 디자인 검토는 차단 문제0개로 승인했다. 기존 자동수집23개·반응24개·읽기 비교5개·집중 UI6개와 SW151 worker→152 현재 모듈의 PWA9개가 통과했다. 언어는 원실행13개와 새 전역 설정 표시 기대를 맞춘 집중1개, 발견은 원실행18개와 간결해진 빈 목록 문구를 맞춘 집중1개를 구분한다. 초기 테스트 준비 helper 누락·혼합 소스 판·옛 표시 기대의 실패 기록은 보존하며, 핵심 데이터 단언·시간 제한을 완화하지 않았다. PWA는 실제 공개151과 worker 원본 일치를 별도로 확인했고 현재SHELL166/설치15모듈·읽기 비교 원시 revision2를 보존했다. 전체 과거151앱·실제 기기 검증으로 확대하지 않는다.

통합 글쓰기 여정에서 설정 안의 제외한 글로 초점을 복원하지 못한 회귀를 발견해 설정/피드의 위치 기억을 분리했다. 최종 수정 후 기존 준비2개와 글 완주1개의 연속 검수를 통과했고, 제외한 원행 초점과 내부 설정의 scroll200 왕복을 확인했다. 기존 뉴스 원형9개 전체는 최종 CI에서 다시 실행한다. 첫 화면44px 단언의 초기 단발 실패 원인은 확정하지 않았으며 원본을 보존했다. 글꼴·유한 애니메이션·두 프레임 준비 뒤 같은44px 단언을 통과했고 수치나 시간 제한을 완화하지 않았다.

정확한 최종 소스의 로컬 검사·독립 최종 검토·PR/main CI와 배포 artifact/공개 파일/배포본 여정은 [이 변경의 PR 기록](https://github.com/wonchance-art/life-haedo/pulls?q=is%3Apr+head%3Acodex%2Fnews-minimal-20261021)을 따른다. 기존 기사 접근·반응·설정 왕복·저장 실패 복구를 자동으로 끝낼 수 있는 범위까지 함께 마감한다.
