# unslop 점검표로 본 배포 화면 (2026-11-11)

- **기준:** main `c767df3`, 캐시 판 `haedo-v217`.
- **성격:** unslop 지침을 참고한 **수동 점검**이다. 점수나 자동 검사 통과가 아니다.
  - unslop의 snapshot·story 스크립트와 이미지 생성은 설치하지 않았으며 실행하지 않았다.
  - 이번 범위는 점검과 보고이고 앱 코드는 바꾸지 않았다.
- **적용 범위:** [해도 적용 범위](../../.agents/skills/unslop/INSTALLATION.md)를 원본보다 우선해 따랐다. 방향은 [DESIGN.md](../../DESIGN.md)·[PRODUCT.md](../../PRODUCT.md)에서 가져왔고 새 방향은 짓지 않았다.
- **방법:**
  - Chromium headless의 실제 화면을 1440·820·390px(배율 1)에서 봤다.
  - 화면마다 [signs.md](../../.agents/skills/unslop/references/signs.md)의 묶음(표면·색 / 글꼴 / 아이콘 / 간격 / 문구 / 구성 요소 / 움직임 / 템플릿 느낌)을 대조했다. 랜딩·그림 항목은 로그인 전 공개 화면에만 적용했다.
  - 굵기·크기·자간·반지름·그라디언트·`transition`·애니메이션·대문자·이모지·아이콘 크기는 계산된 스타일에서 쟀다.
- **샘플:** 검사용 가짜 클라우드(FakeCloud·ShareCloud·PlatformTables)의 익명 샘플만 썼다. 공개 표지만 임시 PostgreSQL 16(UTF8) 클러스터를 썼다. 개인 기록·실계정·운영 DB는 쓰지 않았다.
- **캡처:** 화면 약 55개 × 3폭, 약 170장을 찍었다. 대표 9장만 [unslop-audit-2026-11/](unslop-audit-2026-11/)에 넣었다.
- **콘솔·페이지 오류:** 의도해서 넣은 실패(AI 503)와 검사 틀이 내는 알려진 서비스워커 메시지 말고는 0건이다. 외부 요청도 0건이다.

표기:
- **관찰**은 눈으로 본 판단, **측정**은 계산된 값이다.
- **수정 중**은 총괄이 통합 중인 핵심 기능 수정 묶음과 겹치는 화면이다. 결과를 반영하기 전에 그 묶음과 맞춰 봐야 한다.
  - 대상: 글 공개·보관 목록과 공개 상태, 편집기 더 보기 메뉴·저장 상태, 자료 읽기의 출처 정보·담기 패널, `내 사본 수정` 초안, 연간 계획 충돌 안내, 설정 동기화 수동 비교.

> 2026-11-12: "수정 중" 항목은 v218(#249)에서 다시 봤다. 결과는 [v218 화면 디자인 점검](v218-design-check.md) 3절에 있다. 출처 정보 시각·버튼 간격·담기 간격은 해소됐다.

전체 판단:
- 해도의 앱 화면은 unslop 기준으로 **가벼운 정도(Light slop)**다.
- 다음 전형적 신호는 하나도 없다(측정, 전 화면 0건): 보라·파랑 그라디언트, 빛 번짐, 그라디언트 글자, 이모지 라벨, `New ✨` 배지, 무한 반복 애니메이션.
- 남은 신호는 다섯 가지 일관성 문제다.
  1. 팔레트 밖 파랑 `#3156d3`이 두 번째 강조색으로 남아 있다.
  2. 조작 모양이 화면마다 다르다(알약 999px·원형 50%·8–12px 혼재).
  3. 아이콘 세트가 섞였다(Quill 기본 SVG, 글꼴 문양, 네이티브 ▶ 표식).
  4. 16px 미만 글자의 음수 자간과 단계 밖 글자 크기가 일부 남았다.
  5. 묶음 간격 0px 같은 간격 결함이 있다.
- 신호가 가장 많이 모인 곳은 다른 틀을 쓰는 연표 편집기다.

| 상태 문구 다듬기 | `저장됨 · 계정에 올림` 등 소유자 문장은 그대로 | AGENTS 11-02 결정 |
| AI에 반짝임 금지 | 서식 패널 AI 표시는 결정된 모양 | [AI 글 표시](ai-authorship.md) |
| 빈 상태 문장의 끝 마침표 | `이 날 기록이 없어요.`는 정한 문장 | [일정 통합 정리](schedule-consolidation.md) S7 |
| 대문자 라벨 | 단계 막대 Y·Q·M·W·D는 결정된 글자 | expert-design-brief 결정 표 |

공통으로 신호가 아니었던 것(측정):
- 글자색은 ink·보조·틸·흰색 네 역할이다.
- 그림자는 모두 중립색이다(색 그림자·빛 번짐 0).
- 단축키 키캡은 의도된 모양이다.
- 단계 막대의 중첩 반지름이 맞다(바깥 14px, 안쪽 10px, `ui.css:287-289`).

## 소유자 판단이 필요한 것

1. **O-1 굵기 체계:** 화면에 400~750이 7~8가지 쓰이고, 13~15px에서 550·600·650이 나란히 쓰인다. 줄인다면 550·650 → 600, 750 → 700 같은 안이 가능하다. 다만 DESIGN의 제목 700·프로필 750은 소유자 기록값이다. [도입 기록](unslop.md)도 숫자만으로 바꾸지 않는다고 적었다.
2. **O-2 로그인 전 홈 구호형 제목:** `생각은 글로. 취향은 나답게.`를 유지할지, 기능을 말하는 제목으로 바꿀지.
3. **O-3 공개 블로그:** 제목 없는 글을 `제목 없는 글` 대신 첫 문장으로 보일지.
4. **O-4 `공개 상태 다시 확인`:** 글자 버튼과 cloud 아이콘 중 하나로 맞출지.
5. **O-5 연표 편집기의 검은 원 `+`:** 글쓰기와 두 번째 강조를 다투는데, 그대로 둘지.
6. **O-6 연표 숫자 정밀도:** `+0.18`과 `+0.5`처럼 정밀도가 다른 것을 맞출지.
7. **O-7 일정 목록 `글 읽기`:** 틸 글자와 화살표 4쌍을 회색 보조로 낮출지.
8. **O-8 오늘 표시:** 다섯 가지 모양을 하나로 맞출지.
9. **O-9 백업 화면 강조:** 틸 채움이 2개인데 그대로 둘지.
10. **O-10 글 공개·보관 행 버튼:** 행마다 3개인데 줄일지 (수정 중).
11. **O-11 글 공개·보관 상태 문구:** `계정에 올림`을 소유자 문구 `저장됨 · 계정에 올림`으로 맞출지 (수정 중).
12. **O-12 AI 제안 아이콘:** `수정`과 같은 펜 그림을 그대로 둘지.
13. **O-13 빈 편집기 안내:** 저장 상태 자리에 그대로 둘지 (수정 중).
14. **O-14 담기 아이콘 개념:** 정리할지 (수정 중).
15. **O-15 발췌 탭 칩:** 이름 반복과 같은 모양을 정리할지.

## 확인하지 않은 것

- 실제 Mac·iPad·iPhone, Safari/WebKit, VoiceOver, 화면 배율 2 이상.
- 1920px와 1101–1439px 2단 폭, hover·누름 모양(계산된 값만 확인).
- 빈 상태·로딩·오류 상태 대부분.
- 수정 중인 화면의 최신 모습: 공개 미리보기, 동기화 비교, 연간 계획 충돌 안내.
- 연표 편집기의 hover 카드·지도 경로 버튼·접근 실패·비밀번호 게이트·시작 안내.
- AI 미설정 상태는 가짜 서버의 503 응답으로만 렌더했다(설정이 없는 클라이언트 경로 미확인).
- 공개 표지는 임시 PostgreSQL 16 UTF8로 렌더했다(저장소 기본은 postgres 17 컨테이너). blog·share는 HTTP 모의 응답이다.
- 대비는 일부 항목만 쟀다.
