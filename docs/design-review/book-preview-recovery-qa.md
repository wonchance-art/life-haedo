# 책자 미리보기 복구 검증 · 2026-10-10

## 범위와 보존

PR #57로 배포한 A 디자인에서 남은 Codex 내장 브라우저의 책자 준비 지연을 수정했다. 출발점은 main `d22ed42518d55b9b5c05fc571500eff217c4bde4`다. 원문·정확 버전·발췌·계정별 저장·동기화·개정본·JSON 백업·공개 범위와 디자인을 유지한다. SQL·Auth·운영 데이터·다른 열린 PR은 수정하지 않았다.

## 재현과 선택

- 같은 익명 네 장 책자·sandbox·CSP에서 Blob 미리보기는 내장 브라우저의 15초 제한을 넘었고, `srcdoc`은 표시됐다. 종전에는 준비 실패가 HTML 파일 받기도 막았다.
- `srcdoc`의 상대 목차 URL은 부모 앱을 기준으로 해석된다. 부모의 클릭 리스너는 Chromium에서 작동했지만 WebKit의 스크립트 없는 sandbox에서는 차단됐다. 이 초기 실패 기록도 `.local/book-preview-recovery/`에 보존했다.
- 최종 구현은 생성된 유효 목차에만 `about:srcdoc#…` 목적지를 지정한다. 기본 링크 이동을 사용하며 자식 스크립트·새 의존성·CSP 완화가 없다. 독립 HTML과 Blob 인쇄 문서에는 기존 상대 `#` 링크를 유지한다.
- 미리보기 목적지를 먼저 검증한 뒤 이 접두사만 제거해 전체 DOM과 독립 HTML/인쇄 입력을 대조한다. 포함 범위·본문·스타일·출처는 동일하다. 오류·세대 변경·계정 변경의 취소 경로도 유지한다.

검증은 격리된 익명 Auth/IndexedDB와 익명 복원 사본에서 수행했다. 테스트 도구가 srcdoc에도 주입하려던 초기화 스크립트의 sandbox 차단은 `sandboxedHarnessScripts`로 원문 그대로 별도 기록하며 앱 오류로 숨기지 않는다. 승인된 보호 설정은 유지하고 예상하지 않은 콘솔/페이지 오류·외부 요청은 실패 처리한다.

로컬 증거는 `.local/book-preview-recovery/`와 `.local/book-edition/`이다. GitHub CI는 `.local/book-edition/` 보고서·스크린샷·HTML/PDF를 브라우저 증거 아티팩트에 포함한다. 모두 익명 샘플이며 키·비밀번호·개인 자료를 보고에 넣지 않는다.

## 제약과 다음 확인

화면 크기 모사는 실제 Apple 기기·한국어 OS IME·소프트 키보드·Files 검증이 아니다. 사용자가 실기기 대기를 해제한 범위에 따라 브라우저 검사로 판단한다. WebKit 검사는 PDF 생성 검사와 구분한다. 내장 브라우저의 네이티브 인쇄/저장 대화상자 지원은 이 수정 범위에 포함되지 않으며, HTML을 받은 뒤 인쇄 지원 브라우저에서 열어 PDF로 저장할 수 있다.

기존 A 통합/배포는 [PR #57](https://github.com/wonchance-art/life-haedo/pull/57)에서 완료됐다. 이 후속 수정은 CI 이후 한 번만 병합·배포하고 공개 주소의 v90 자산·책자 표시·HTML 받기를 재확인한다. 운영 재현 또는 문서 격리/출력 손상이 있으면 추가 배포를 멈추고 원인을 수정한다.
