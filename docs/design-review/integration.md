# 자료 검색·원문 디자인 통합

후속 작업은 [가져오기·내 발췌·주제 모음 정리](collections-integration.md)를 따른다. 아래는 첫 통합의 구현·검증 이력이다.

2026-10-04 KST · 로컬 구현·검증 완료. 사용자가 승인한 **본문 중심 한 열과 A · 둥근 따옴표**를 실제 `life.html`의 검색 → 원문 → 발췌 저장 → 목록 복귀에 연결했다. 이전 `social-sample.html`의 메모리 시안과 구분하며, 이번 디자인 변경은 공개 배포 전이다.

## 범위와 선택

자료 제목·일치 구절·출처가 먼저 보이도록 한 열로 정리하고 기본 탐색은 아이콘으로 줄인다. 필터·출처 상세·발췌 입력은 필요할 때 연다. 작업공간·동기화·백업은 관리 경로에 보존한다. 제목·확보 범위·원문 버전·오류 복구 설명은 의미 있는 글자로 남긴다.

긴 글은 페이지에서 자연스럽게 읽고 선택하는 본문으로 바꾼다. 본문에는 원문 문자열을 안전한 텍스트 노드로 넣고 선택 위치를 기존 raw UTF-16 좌표에 연결한다. 키보드 범위 선택을 위한 읽기 전용 입력도 제공한다. 원문의 버전·CRLF·공백·이모지 좌표를 보기 좋게 정규화해서 저장하지 않는다.

더 단순한 대안은 기존 읽기 전용 textarea에 스타일만 적용하는 것이었다. 선택 좌표 계약을 그대로 쓸 수 있지만 긴 원문을 작은 내부 스크롤에서 읽는 부담이 남는다. 본문 중심의 페이지 읽기를 위해 DOM 본문을 선택하되, 저장 모델을 바꾸지 않고 정확한 텍스트와 기존 회귀 사례로 변환 경계를 확인한다. 실제 Apple 기기의 선택 손잡이는 별도 검증 대상이다.

## 재사용과 책임

[Lucide 1.51.0](../../vendor/lucide/README.md)의 로컬 SVG와 기존 기본 CSS·DOM을 재사용한다. 출처는 고정 commit `45b0e148db4ee4d748340d0f99982aa1c2159d52`, ISC/Feather MIT 고지는 `vendor/lucide/LICENSE`에 보존되어 있다. 인용은 사용자가 확정한 해도의 A 도형이다. 관리·다운로드·클라우드 등 추가 도형은 단순한 자체 UI 기하 도형이며 공통 파일에서 원본 재사용과 구분한다. 동일한 24×24 좌표계, 2단위 둥근 선, 20px 그림과 최소 44px 조작 영역을 공유한다.

공통 아이콘은 `assets/life/icons.js`의 `HaedoLife.Icons.create(name, { size: 20 })`로 생성한다. SVG는 장식으로 숨기고 실제 버튼·링크에 접근 가능한 이름을 둔다. 키보드 초점·hover 도움말과 Escape 닫기를 제공하며 터치에 hover를 요구하지 않는다.

새 UI 라이브러리·아이콘 런타임·외부 폰트를 추가하지 않는다. 이미 검토한 daisyUI는 플랫폼의 기존 화면에 남기고 자료 화면은 자체 범위 안의 토큰과 컴포넌트로 다룬다. 기존 정적 JavaScript 앱에 필요한 것은 탐색·입력·읽기·상태 표현이므로 프레임워크나 빌드를 추가할 이유가 없다. 기존 [공식 배포·제품 참고 기록](references.md)과 [아이콘 출처](../../vendor/lucide/README.md)를 재사용하며, 이번 작업에서 모든 후보의 최신판을 재조사했다고 보고하지 않는다.

디자인 책임자는 **root 한 명**이다. 여섯 담당이 파일 경계를 나누어 병렬 작업하며 공통 CSS, 최종 시각 기준과 통합 판단은 책임자가 맡는다.

| 담당 | 책임 |
| --- | --- |
| 화면 구현 | 실제 검색·원문·발췌·탐색 UI 연결 |
| 공통 컴포넌트 | 공통 HTML·아이콘·계정 셸 검토 |
| 배포 구성 | 공개 산출물·서비스워커의 정적 자원 연결 |
| 기능 회귀 | 저장·검색·버전·발췌·백업 및 접근 경로 검사 |
| 시각 검토 | 1440·820·390px 캡처, 상태·한글·접근성 검사 |
| 문서·독립 검토 | 보존 반례, 구현/검증 범위와 후속 단계 기록 |

## 반드시 보존할 흐름

- 검색에서 **이전 버전**이 일치하면 그 버전과 실제 위치를 연다. 제목만 일치할 때 본문 인용이나 이전 읽기 선택을 검색 결과로 꾸미지 않는다.
- DOM 선택·키보드 선택 모두 원문 문자열의 같은 구절·버전·raw UTF-16 좌표로 저장한다. CRLF와 이모지도 기존 원문을 바꾸지 않는다.
- 링크만 보관한 자료는 본문 미확보 상태를 유지하며 발췌 저장을 제공하지 않는다.
- 발췌 도구를 닫으면 읽던 위치와 도구 초점으로 돌아간다. 저장 전 초안과 선택 구간을 버리지 않는다.
- 목록 복귀는 검색어·원천 필터·목록 위치·열었던 결과의 초점을 유지한다.
- 작업공간 전환·로그인·동기화·백업·사본 복원과 출처 상세에 계속 접근할 수 있다. 로그인만으로 미연결 자료를 올리지 않는다.

## 직접 확인하기

저장소를 실행할 수 있는 컴퓨터에서 `npm run dev` 후 `http://127.0.0.1:4173/life.html`을 연다. 이 Cloud 세션의 localhost를 외부에서 여는 미리보기 링크는 제공하지 않는다. 개인 화면에는 기존 공용 인증 설정이 필요하다. 로컬 저장은 공개 사이트 저장과 별개이므로 개인 자료를 옮기지 말고 익명 자료로 확인한다.

1. **가져오기**에서 익명 본문이나 TXT/Markdown 파일을 제공하고 출처 확인 후 자료를 보관한다.
2. **원천 기록**에서 기억나는 구절을 검색한다. **검색 필터**에서 원천을 고르고 결과 제목을 열면 일치한 버전의 실제 구간을 읽는다.
3. 본문 구절을 선택한 뒤 **발췌와 주제 연결** 아이콘을 연다. 필요한 주제·메모를 입력하고 **선택 구절 모음에 추가**를 누른다. 키보드 선택은 패널의 **키보드로 구절 선택**에서 한다.
4. **검색 결과로 돌아가기**로 검색어·필터·목록 위치를 확인한다. **모아보기**에서 새 발췌를 열어 같은 원문을 다시 확인한다.
5. **자료 관리 → 내보내기·사본 복원**에서 자료 JSON을 내려받고 새 사본으로 복원한다. 기존 작업공간은 그대로 남아야 한다.

## 검증 기록

아래는 이번 코드에 대한 실행 결과다. 과거 시안 검사와 이번 실제 자료 UI 검사를 합산하지 않는다.

| 구분 | 이번 결과 |
| --- | --- |
| 정적 검사 | `npm run check`: HTML 16 / JS 33 / 로컬 참조 171 / PWA 통과 |
| 기능 회귀 | Node 182/182(배포 구성 17개 포함), Chromium 61/61(자료 52 + 플랫폼 9) 통과 |
| 브라우저 크기·시각 검토 | `node scripts/check-life-design.cjs` 201/201 통과. 34장면 캡처, 대표 10장과 가져오기·복원 화면 직접 검토 |
| 실제 Mac·iPad·iPhone | 이번 디자인의 실기 검증 미실시 |
| 공개 배포 | 이번 디자인 변경 미배포 |

Linux Chromium 151.0.7922.173에서 1440×1000·820×1000·390×844px와 1180×820px 가로 배치를 검사했다. 익명 자료 28건·원문 버전 29개로 긴 제목·많은 자료·빈/로딩/오류·링크 전용·출처·발췌·관리 경로를 확인했다. 가로 넘침, 44px 미만 조작, 16px 미만 입력, 접근 이름 누락, 예기치 않은 console/pageerror·외부 요청은 0건이었다. 작은 글자 대비 최솟값은 6.05:1이며 Linux의 실제 한글 글꼴은 Noto Sans CJK KR였다. 터치 설정의 tap, Tab 초점, Escape/초점 복귀, 모션 감소와 한글 줄바꿈을 검사했으며 실제 Apple 기기 동작으로 해석하지 않는다.

기능 명령은 `npm test`와 `node tests/life-browser.cjs`(23), `node tests/life-sync-browser.cjs`(14), `node tests/life-batch-browser.cjs`(8), `node tests/life-search-browser.cjs`(7)이다. 자료 브라우저 검사에서 예기치 않은 console/pageerror는 0건이며, 의도한 오프라인 Auth 1건·전송/스키마 실패 9건은 복구 검사로 구분했다. 반복 구절의 역방향 DOM 선택, CRLF·이모지·결합 문자, 이전 버전 발췌, 패널 닫기/재열기 후 키보드 선택과 메모 보존, 정확한 raw 좌표 저장을 확인했다. 읽기 전용 입력의 브라우저 키보드 동작에 맞춰 **첫 줄 선택 → Shift 확장** 경로도 제공한다. 한글 조합 이벤트 모사는 실제 한글 IME 체험을 뜻하지 않는다.

독립 코드 검토에서 키보드 선택을 과거 DOM 선택으로 덮을 수 있는 경계와 자료 제목을 접근 가능한 이름에서 지우는 문제를 찾아 보완했다. 해당 회귀와 대표 데스크톱 검색·휴대전화 폭 원문 이미지를 별도로 대조했다.

공개 산출물은 자료 아이콘과 Lucide 고지를 포함하고, 시안 HTML·샘플·스크린샷·스킬은 제외한다. 이전 산출물의 SW v53 → v54 업데이트에서 원문·초안·기존 localStorage 보존과 새 HTML/JS/CSS/아이콘의 해시 일치를 별도 격리 브라우저에서 확인했다. 최신 공개 산출물 기준 플랫폼 9/9와 현재 제품 파일 6개의 해시 6/6 일치를 확인했으며 예상 밖 오류 0건, 의도한 callback/전송 오류 1건이었다. 계정 메뉴의 키보드 열기·닫기·초점 복귀와 초안 저장 실패 시 로그아웃 취소도 모의 Auth로 확인했다.

검증은 격리된 브라우저와 익명 합성 자료로 수행하며 실제 계정·개인 기록·서버 합성 자료를 만들지 않는다. 기존 PR #17/#19는 병합되었고 Google 설정·실제 로그인은 이전 인계와 사용자 확인으로 완료된 기반이다. 이번 디자인 검사에서 실제 로그인이나 서버 SQL 검사를 다시 수행했다고 보고하지 않는다.

## 다음 작업

이번에는 검색·원문·발췌 저장의 실제 연결을 완성했다. 가져오기·내 발췌·주제 모음·시간 보기·동기화·백업/복원에는 공통 탐색과 스타일을 연결했지만 각 화면의 세부 정보 구성을 전면 개선한 것은 아니다. 다음 묶음에서 실제 자료 입력과 관리 흐름을 기준으로 차례로 다듬는다. 실제 Mac/iPad/iPhone에서 한글 입력, 선택 손잡이, Files 백업 보관·재선택을 확인한 후 공개 적용한다. 자료 통합 기능 확대는 그 다음이며 디자인 변경 때문에 저장 형식이나 자동 업로드 범위를 늘리지 않는다.
