## 발견과 수정

- #94 화면 개선은 #96에 완전히 포함되지 않았다. 집필·프로필·폰트는 #94에서, 정확 버전·9칸/글 복귀·검증 게이트는 #96에서 보존했다.
- Mac의 /var→/private/var 별칭 뒤 바깥쪽 symlink가 원본 출력 경로 보호를 피했다. 기존 단위 검사에서 재현했고 상위 경로를 모두 canonicalize해 차단했다. 검사 오류/정책 변경 가설 대신 실제 경로 별칭이 원인임을 확인했고 같은 회귀 11개 통과.
- 9칸의 정확 글 열기가 이전 접힌 작성기 상태 뒤에 가려졌다. 파일 복원·원문 해시와 저장 글 조회는 정상이었고, 저장 오류나 잘못된 참조 가설이 아니라 editor view 복원 순서가 원인이었다. 명시 글/초안 요청은 접힘 복원보다 우선 열도록 수정했다. 원문·복원 회귀에서 재확인한다.

- 통합된 원본 첨부의 정확 원문 버튼이 모달 종료 후에도 busy 상태로 이동을 막았다. 모달이 실제 닫혔고 원문/계정 조회가 정상인 점으로 경로 누락·인증 실패 가설을 배제했다. 닫힌 인스턴스의 dirty/flush는 대기를 요구하지 않도록 고치고 실제 관리 진입→정확 옛 버전→관리 복귀 회귀를 추가했다.

- 최종 CI가 새 서체를 공개 읽기의 CSP에서 차단하는 결함과, 새 접힘/첫 글 진입을 따르지 않는 과거 검사를 잡았다. 공개 페이지는 같은 출처 폰트만 허용하고, 검사는 실제 펼치기/보이는 첫 글·일반 로그인 경로로 수정했다. 저장·RLS·공개 범위 단언은 제거하지 않았다.

- 홈의 native details toggle 이벤트가 지연될 때 복귀 상태가 접힌 것으로 캡처되는 통합 회귀를 재현했다. leave()의 보호보다 먼저 captureState()가 실행되는 순서를 확인해, 캡처 시 현재 DOM.open을 읽도록 수정했다. 의도적 toggle 지연·키보드 왕복 회귀로 검증한다.
