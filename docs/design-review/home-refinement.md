# 홈의 작성·찾기·읽기 정리

2026-10-18 KST. [사용 흐름 개편](blog-user-journeys.md) 뒤 홈 재검토에서 승인한 세부 수선이다. 흰색·차콜, 한 열 본문과 기존 저장·공개 경계는 유지한다.

## 바뀐 화면과 동작

- 글·초안·보관한 글이 모두 없으면 작은 프로필과 `첫 글 쓰기`를 보여준다. 필요 없는 작성 행·탭·검색을 감춘다. 조회 실패를 빈 홈으로 표시하지 않는다.
- 일반 홈은 작은 프로필 → 클릭·키보드로 여는 작성 행 → 탭과 접힌 검색 → 실제 글 순서다. 같은 작성자의 이름·아바타를 글마다 반복하지 않고 날짜·비공개·브라우저 보관 범위를 작게 남긴다. 로컬 날짜의 지난 연도에는 연도를 표시한다.
- 검색 안내는 현재 탭의 범위를 설명한다. 읽기·수정·프로필 왕복 뒤 검색어와 검색 펼침을 보존하며, 초안 탭에는 별도 최신 초안 행을 반복하지 않는다.
- 사진이 있는 각 글의 미리보기를 화면 접근 때 조회한다. 첫 네 글 뒤의 프레임을 영구 로딩 상태로 남기지 않는다. 원본·순서·설명·대체 텍스트·ZIP은 바꾸지 않는다.
- 태블릿 탐색에도 목적지 라벨을 둔다. 프로필의 소개 숨김은 실제 홈 문구를 감춘다. 프로필 실패와 글 조회 실패를 구분하고, 구성 재시도 뒤 펼친 자료실의 선택 자료 입구도 갱신한다.

자료 형식 변환, 새 서버·라이브러리, 공개·자동 동기화 확장은 없다. [현행 시각 규칙](../../DESIGN.md)과 기존 정확 버전·검색 복귀·계정 격리 계약을 따른다.

## 확인 근거

대표 화면: [이전 홈](evidence/home-refinement/before-home-390.png) · [현재 홈](evidence/home-refinement/after-home-390.png) · [태블릿 홈](evidence/home-refinement/after-home-820.png) · [320px 빈 홈](evidence/home-refinement/after-empty-320.png). 같은 익명 샘플의 일반 홈에서 첫 글 제목의 상단 위치는 390px 폭에서 533.6→338px, 820·1440px 폭에서 539.5→354px로 옮겨졌다. 소개·상시 검색·작성자 반복을 줄인 결과이며 사용성 점수로 해석하지 않는다. 직접 이미지 검토에서도 작성·탭·본문의 순서와 태블릿 라벨을 확인했다.

홈 수선·P0 브라우저 실행의 실제 콘솔/페이지 오류·외부 요청은 0이며, 홈 수선의 원격 쓰기도 0이다. 전후 원본은 `.local/home-review/`와 `.local/home-refinement/visual/`, 기능 근거는 `.local/home-refinement/qa/browser-report.json`과 `preservation/browser-report.json`, 시각 근거는 `visual/report.json`이다. 기존 검토와 이번 결과를 합산하지 않는다.

홈 보존·첫 작성 근거는 `.local/home-refinement/preservation/home-entry/browser-report.json`과 `blog-platform/browser-report.json`, SNS 최종 실행은 `sns-final/browser-report.json`, PWA는 `.local/home-refinement/pwa/report.json`이다. 기존 검사에는 접힌 검색을 실제로 여는 동작·태블릿의 보이는 라벨·임의 검증 포트의 HTTP fixture를 반영했다. 제품의 저장·계정 격리 조건을 완화하지 않는다.

날짜 추가 검사는 `.local/home-refinement/qa/date-boundary-report.json`이다. Asia/Seoul에서 UTC 12월 31일 14:59/15:01의 여섯 글을 세 형식으로 읽고 지난 연도·로컬 1월 1일·저장/수정 구분·원래 `datetime`·전체 연도 tooltip을 확인했다.

직접 확인은 `npm run dev` → `http://127.0.0.1:4173`에서 빈 홈의 첫 글 저장·읽기·복귀, 기존 홈의 검색 펼침·탭 변경·정확 항목 왕복 순서다. 집중 회귀는 서버와 Playwright 경로를 준비한 뒤 `node tests/home-refinement-browser.cjs`로 실행한다.

브라우저 폭 검사는 실제 Mac·iPad·iPhone, OS 한글 입력기·Files·VoiceOver 체험과 구분한다. 실제 Google 로그인·운영 DB/RLS·공개 배포는 이 홈 수선의 로컬 검증에 포함하지 않는다.
