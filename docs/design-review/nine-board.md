# 영역별 9칸 구성

2026-10-14. mytop9books 검토 뒤 사용자가 요청한 ‘하나의 대표 9개’와 ‘각 영역 최대 9개’를 구현한다. 추천을 물은 사용자에게 자유로운 영역 최대 9개 × 항목 최대 9개를 추천하고 이 방향으로 진행한다고 안내했다. 중심 주제와 주변 8개가 고정된 만다라 방식은 이번 저장 계약에 강제하지 않는다.

## 사용 흐름과 완료 조건

내 페이지 → **9칸 구성** → 새 구성 → 제목·영역 이름 → 빈 칸에서 기존 CollectionPicker로 대상 선택 또는 직접 입력 → 제목·창작자·출처 검토와 직접 쓴 선택 이유 → 담기 → 자동 로컬 보관 → 9칸 미리보기. 영역 하나는 3×3이고 여러 영역은 전체 개요에서 영역별 3×3으로 들어간다. 영역/항목은 반드시 9개를 채울 필요가 없다. 빈 칸은 빈 상태로 남고 순위로 표시하지 않는다.

기존 글·초안·컬렉션을 재편집하거나 기존 12개 첨부를 잘라 보여주는 방식은 피했다. 기존 첨부 snapshot 렌더러와 선택창을 재사용하면서 선택 결과를 별도로 저장한다. 컬렉션 사전 등록은 필수가 아니며 기존 데이터의 본문·개인 메모·태그·details는 복사하지 않는다. 선택 이유는 사용자가 여기서 직접 입력한다. 사진/표지 없는 경우에도 제목·창작자·유형·출처를 읽을 수 있다. 외부 이미지 자동 로드와 새 공개 서버 형식은 추가하지 않는다.

## 저장과 복구

- `nine-board:${workspaceId}` 로컬 meta 한 행. `life-nine-board-v1`, 계정 소유권 검사, revision CAS, 트랜잭션 완료 후 성공. 최대 구성 20개, 영역 9개, 영역별 항목 9개, 2 MiB. 기존 IndexedDB 버전/테이블·workbench-v1·공개 payload·운영 SQL을 변경하지 않는다.
- 입력 DOM은 자동 보관 응답으로 재생성하지 않는다. 한글 조합·미반영 폼 중에는 자동 보관을 기다리며 정상 입력에 실패 안내를 띄우지 않는다. 문자/전체 용량을 넘긴 필드는 원래 반영값을 보존하고 현재 입력을 화면에서 고칠 수 있게 남긴다. 저장 중 추가 입력은 tick으로 구분하고 성공 payload만 비교 기준으로 남긴다. 한글 조합과 반영 전 대상 폼은 이동/미리보기/파일 출력 전에 마치도록 안내한다. 대상의 반영 전 폼은 메모리이며 강제 종료 후 복구하지 못한다.
- 쓰기 실패는 메모리 변경과 재시도를 유지한다. 두 탭 충돌 시 원격 자료를 덮어쓰지 않는다. **내 변경을 새 사본으로 보관**은 마지막 성공 payload 이후 달라진 구성만 최신 저장본 뒤에 새 식별자로 원자적으로 붙인다. 기존 저장본과 내 변경을 모두 보존하며 실패/한도/추가 경합에서는 부분 사본을 만들지 않는다. 복구/파일 설치 중에는 편집을 잠가 응답 대기 중 입력을 덮어쓰지 않는다.
- JSON 백업은 모든 구성의 정확한 문자열·출처·이유를 포함하는 `life-nine-board-backup-v1`. 계정·작업공간 식별자/저장 revision 없이 다른 공간에서 재사용한다. 파일 확인에서 내용을 읽고 명시적으로 새 사본을 추가한다. 잘못된 형식·숨은 필드·unsafe URL·한도 초과는 거절한다.
- HTML은 선택한 구성 하나의 모든 영역을 읽을 수 있는 독립 파일이다. 평문 escape, 안전 URL, 외부 리소스/스크립트 없음, CSP, 창 분리. 공개 링크 생성이나 파일 보관 완료로 표시하지 않는다. 기존 자료·구성 백업, 동기화, 공개 사본은 9칸 데이터를 포함하지 않는다. 해당 구분은 파일 관리에 표시한다.

## 반대 검토와 한계

전체 81개 항목을 모바일에서 한 화면에 압축하면 읽기/44px 조작을 해친다. 전체 보기는 영역 이름·선택한 제목·실제 개수를 보여 주고, 하나를 열어 항목과 출처·선택 이유를 읽는다. 3×3을 유지하면서 긴 한글 제목은 줄바꿈한다. 이미지 자동 요청·드래그 전용 편집·억지로 채운 빈 칸을 사용하지 않는다. 순서 이동은 버튼으로 하며 이유를 편집한 채 이동해도 함께 반영한다.

아직 없는 것: 9칸 구성의 서버 공개 링크, 기기 간 자동 동기화, 중심 1+주변 8의 고정 만다라 배치, 이미지 내보내기. 이번 HTML/JSON 파일 경로로 보여 주기와 재편집을 완결한다. 실제 Apple 기기 체험은 Local 사용자가 후속 확인한다. 병합·운영 배포는 Local 담당이다.

[후속 파일 범위·선택 복구](nine-board-selective-recovery.md)는 현재 구성 하나의 JSON과 전체 백업을 구분하고 필요한 구성만 선택해 복원한다. 기존 v1 형식과 이 문서의 데이터 보존 계약을 유지한다.
