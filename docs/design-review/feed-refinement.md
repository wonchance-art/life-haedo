# 본문 중심 피드 마감

2026-10-04 KST · 사용자의 후속 요청에 따라 자료와 발췌를 독립 피드로 구분하고, 본문 밖의 반복 문구를 줄였다. 디자인 책임자는 root이며 UI와 기능·시각 검토를 두 담당에게 분리했다. 공통 도형과 저장 계약은 유지했다.

## 적용

- 피드 사이에 얇은 선과 여백을 두고 본문 → 내 메모 → 짧은 주제/도구 순서로 배치한다. 내 메모는 기존 사용자 도형과 접근 가능한 이름으로 구분하며 회색 상자와 반복 제목을 없앴다.
- 원문 열기·출처 정보·관리는 기존 book/info/settings 도형을 사용한다. 24×24 좌표계·둥근 2단위 선·20px 그림·44px 조작 영역을 유지하며 승인한 A 따옴표는 바꾸지 않았다. 새 아이콘 패키지는 추가하지 않았다.
- 출처·버전은 정보 아이콘에서 펼치고, 각 출처의 정확한 원문을 연다. 두 번째 출처에서 돌아와도 패널을 복구하고 같은 참조에 초점을 돌려준다. 제거는 관리 아이콘에서 펼치며 기존 확인과 원문 보존을 유지한다.
- 검색 결과는 제목·본문을 먼저 보여 준다. 원천과 본문 일부/미확보·이전 버전·제목 일치 같은 판단 정보는 짧게 남기고 상세는 접는다.
- 정상 초기 안내와 정상 피드 하단의 반복 보관 설명만 화면에서 줄인다. 접근 가능한 안내는 남기며 저장·삭제 결과, 대기/전송·오류·충돌·계정 불일치는 표시한다. 동기화 상태가 바뀔 때도 표시를 갱신한다.
- 긴 아이콘 도움말은 220px 안에서 줄바꿈하며 키보드 초점·Escape와 터치 접근을 보존한다.

## 이번 검증

- 기능 46개 통과: collections 6, source search 7, life 23, 플랫폼 공통 8 + 업데이트 경로 2. 정확한 원문·버전·구절, 복귀 초점, 제거 취소·원문 보존, 재열기와 백업 사본 복원을 확인했다.
- `scripts/check-life-feed-design.cjs`: 100/100 점검, 15장면, 대표 8장 직접 검토. 1440·820·390px에서 최소 텍스트 대비 6.05:1, 가로 넘침·예상 밖 콘솔/페이지 오류 0. 기존 전체 시각 검사를 반복했다고 보고하지 않는다.
- 정적 HTML 16 / JS 33 / 참조 171 / PWA, 서비스워커·공개 산출물 Node 17/17 통과.
- 실제 `e96fed5`와 일치하는 이전 v55와 공개 main `d44772d`의 v53 산출물에서 각각 v56으로 업데이트하며 원문·초안·기존 저장값 보존을 확인했다. 공개 산출물에는 시안·문서·스크린샷을 포함하지 않는다.
- 모의 Auth와 동봉 SDK·계정별 IndexedDB를 사용했다. 실제 Supabase 쓰기는 없었고, life의 의도한 오프라인 Auth 1건과 플랫폼 각 실행의 의도한 callback/전송 실패 1건은 예상 밖 오류와 구분했다.

## 적용과 체험

현재 코드의 병합·배포와 라이브 확인 결과는 [PR #20](https://github.com/wonchance-art/life-haedo/pull/20)에 기록한다. 로컬 검사는 공개 적용이나 실제 Google 로그인 검사를 대신하지 않는다. 실제 Mac/iPad/iPhone의 한글 IME·Files·VoiceOver 체험은 별도로 남아 있다.

로컬에서는 `npm run dev` 후 `life.html`에서 모아보기 → 정보 아이콘 → 두 번째 출처 → 원문 → 목록 복귀를 확인한다. 기본 화면은 본문에 집중하고 상세를 연 뒤에도 정확한 원문 관계가 이어져야 한다. Cloud localhost를 외부 미리보기 링크로 제공하지 않는다.
