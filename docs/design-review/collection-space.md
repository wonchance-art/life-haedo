# 컬렉션: 표지로 고르고 글에 연결하기

2026-10-11 · 디자인 책임 root · 독립 시안, 실제 앱 미연결.

## 이번 사용 목표

같은 가상 앨범·책·도구를 함께 살펴보고, 관심 있는 세 개를 글에 연결한다. 보관함의 모양과 글에 넣는 크기를 실제 브라우저에서 비교하는 첫 단계다. 구현 전체 완료나 실제 자료 저장으로 보고하지 않는다.

- 대상: 앨범, 책의 판본, 영상, 글 링크, 도구, 장소, 기타. 여러 컬렉션에서 같은 대상을 참조한다.
- 컬렉션: 사용자의 목적에 따른 대상 모음. 종류와 별개다.
- 기록: 사용자가 직접 쓴 생각 또는 수집한 정확 버전의 원문. 대상의 메타데이터와 분리한다.
- 기존 `collections` 이름을 쓰는 발췌 화면과 이번 대상 보관함은 의미가 다르다. 기존 함수나 경로를 단순 이름 변경으로 대체하지 않는다.

**A를 기본으로 추천하고 B를 보기 전환으로 제공한다.** 글쓰기 선택기는 A의 작은 표지를 재사용한다. 제목을 잘라 맞추지 않고 줄바꿈하며, 동일 행의 다음 시작선은 그 행에서 가장 긴 카드에 맞춘다. 화면을 채우는 큰 패널·통계·종류별 새 테마는 추가하지 않는다.

시안 상단 A/B와 하단 상태 모사는 검토 도구다. 실제 앱에 그대로 들어갈 메뉴가 아니다. 실제 통합 때는 기존 기록 탐색과 아이콘을 재사용하며 전역 탭을 추가하지 않는다.

## 보존 계약과 후속 구현 순서

이 시안은 운영 CSS·아이콘을 읽기만 한다. 운영 HTML, 저장소, 원문, 버전, 백업, 공개 사본, 서비스워커는 수정하지 않았다. 모든 입력은 DOM textContent/value로 처리한다. 개인 메모는 글에 붙는 제목·만든 사람 카드와 분리한다. 연결 해제는 시안 대상 자체를 제거하지 않는다.

1. **실제 보관·복원**: 기존 계정/작업공간 경계를 재사용하고 대상 ID와 모음 멤버십을 분리한다. 장기 저장 방식은 아직 확정하지 않았다. `storage.js` 원자 트랜잭션, bundle/workbench 검증, 백업 ID 재매핑, 구성 동기화 CAS/서버 용량 제한을 함께 실험한 뒤 형식을 정한다. 기존 책/발췌 자료를 새 대상으로 변환하지 않는다. 수동 등록 → 새로고침 → 다른 계정 격리 → 백업 복원까지 먼저 완결한다.
2. **글과 참조 연결**: 기존 `writing.js`의 불변 원문 버전에 정확히 귀속하는 참조 계약이 필요하다. 시안의 메모리 배열이나 본문 문자열 치환으로 영구 연결을 대신하지 않는다. 대상 수정이 과거 글·공개 사본에 자동 전파되는지 여부를 명시하고 기본은 공개 사본 자동 갱신 없음. 저장 실패·계정 변경·두 탭 충돌 시 글 입력을 보존한다.
3. **메타데이터 후보 조회**: URL 우선, 책/앨범 이름 검색 보조. YouTube 영상과 앨범, 채널과 아티스트, 작품과 판본, 제품과 GitHub 저장소를 구분한다. 정보 출처/조회일/직접 수정 여부를 필드별로 보관하고 재조회가 직접 편집을 덮어쓰지 않게 한다. 후보 확정 전 중복 병합 금지. 실패해도 수동 등록 가능. 제목 중복 경고는 시안용이며 실제 식별자로 쓰지 않는다.
4. **이미지·재생**: API와 표지 이미지 권한·요청 한도·CORS·전송 범위를 공급자별로 확인한다. MusicBrainz/Open Library/Google Books는 아직 후보이며 이번에 도입하지 않았다. 임의 URL fetch 서버를 만들지 않는다. YouTube는 사용자가 재생할 때만 프레임을 생성하고 제목·원본 링크 및 차단 시 대안을 제공한다. 자동 재생·일괄 프레임 로드 없음.

아티스트별 탐색·취향 분석·추천은 실제 수집 후의 후속 범위다. 저장했다고 이용/독서/동의/신념으로 추정하지 않는다.

## 검증과 반대 검토

이번 Chromium 151 검사는 **31개 확인 통과**, 화면 17개를 남겼다. 1440·820·390px에서 가로 넘침과 표지 영역 넘침 없음, 조작 높이 44px 이상, 입력 글자 16px 이상, 계측한 텍스트 최소 대비 5.57:1이다. 키보드 Enter/Escape·모달 Tab 순환·닫기 초점 복귀·터치 탭 모사를 확인했다. 대표 8장면을 직접 검토했다. 외부 요청·console/pageerror는 0, localStorage/sessionStorage/IndexedDB/서비스워커 생성도 0이었다. `npm run check`는 HTML 18 / JS 59 / 참조 271 / PWA 통과이며, 시안 JS 2개와 검사 파일은 별도로 구문 검사했다. 전용 CI 문법·문서 링크·diff 검사와 공개 산출물의 시안 제외를 확인했다.

실행 결과는 [report.json](evidence/collection-space/report.json)에 남긴다. 실제 앱의 저장/동기화 회귀를 실행한 것으로 보고하지 않는다. 이번 변경에는 저장 형식/SQL/런타임 변경이 없으므로 기존 전체 테스트를 중복 실행하지 않았다.

첫 시각 검토에서 휴대전화 폭의 글 표지가 영역을 넘어오는 문제를 발견했다. 표지 폭을 줄이고 실제 표지 경계 검사를 추가했다. 작은 카드의 책 글자 줄바꿈과 초점용 건너뛰기 링크의 비활성 노출도 보완했다. 선택 창의 마지막 버튼에서 Tab이 빠지는 경우를 발견해 모달 내부 순환도 추가하고 다시 확인했다. 자동 통과와 별도로 A/B 및 글쓰기 화면을 직접 보았다.

남은 한계: 실제 Apple 기기, native IME, VoiceOver, 개인 자료, 실제 이미지/API 응답, 영구 저장·동기화·백업·공개는 미검증이다. 단순 시안 후보를 실제 API 성공으로 표시하지 않는다. 익명 12개/84개 샘플 검사는 대규모 라이브러리 성능 보장을 뜻하지 않는다.

## Local 인계

기준 main `29a325b`. PR #56, #58–64는 이번 착수 시 미병합이었다. 이 시안은 그 PR의 앱 코드를 가져오지 않으며 실제 화면의 충돌 해결이나 병합을 대체하지 않는다. 공유 파일에 대한 변경은 공식 사례 기록의 추가뿐이다.

- `docs/prototypes/collection-space/`와 전용 브라우저 검사·전용 CI를 검토한다.
- 실행 경로와 비교 자료는 위 안내를 사용한다. 프로덕션 파일 allowlist에 시안을 추가하지 않는다.
- 운영 SQL·Secrets·캐시 버전 변경은 필요 없다. 병합·배포는 Local 담당이며 이번 Cloud에서는 하지 않는다.
- 다음 구현 전에 최신 병합된 계정/저장/글쓰기 계약을 다시 확인한다. 실제 저장 설계 없이 시안의 상태를 localStorage로 옮겨 운영하지 않는다.
