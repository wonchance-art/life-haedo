### 화면 규칙 (구현한 대로)

- **도구 줄:** 한 줄이다. 문서 순서(키보드 순서)는 `뒤로` → 공개 알약 → `수정`(숨긴 글이면 `목록에 다시 보이기`) → `통합 검색` → `⋯`다. `뒤로`는 왼쪽 끝, 나머지는 오른쪽 끝에 모인다.
  - 1101px 이상: `뒤로` 오른쪽에 경로(`노트 › 글 제목`, 14px). 앞부분은 메뉴의 현재 항목 이름이고 보조색, 글 제목은 먹색이며 길면 말줄임한다. 메뉴와 바로 아래 제목을 되풀이하므로 화면 읽기 프로그램에는 읽히지 않는다(노트·일정 경로와 같은 규칙).
  - 360px 이상: `수정`은 글자만 보인다(시안과 같다. 전에는 아이콘 + 글자였다). 360px에서 다섯 조작이 한 줄에 들어가는 폭이 이 구성에서만 나온다(아래 실측).
  - 360px 미만: 공개 알약은 자물쇠(공개 중이면 지구본), `수정`은 연필 아이콘만 보인다. 접근 이름은 `비공개 · 글 정보`·`글 수정` 그대로다.
  - 알약에 문제 표시(`올리기 실패`·`새로고침 필요`·`맞추는 중`)가 붙거나 공개 여부를 아직 모르면(`글 정보`·`공개 확인 못 함`, 아이콘 없음) 글자를 그대로 보이고, 좁으면 도구 묶음이 둘째 줄로 내려간다.
  - 줄 높이는 작성기 줄과 같다(1440·820에서 65px, 760px 이하 57px). 읽기와 편집을 오갈 때 제목이 움직이지 않는다(D1).
- **`⋯` 메뉴:** `사진 포함 백업` → `이 글 공개·보관` → `근거 포함 파일` → `HTML 읽기 파일 받기` → `사본으로 이어 쓰기` → `목록에서 숨기기` → `삭제`. 흰 바탕, 1px 선, 계약의 그림자, 8px 모서리, 항목 44px.
  - 열린 `⋯`는 선택 면과 1.5px 먹색 테를 함께 보인다(노트 머리의 열린 조작과 같다).
  - 메뉴를 열어도 줄 높이가 늘지 않는다(전에는 20px 늘어 본문이 밀렸다).
  - 760px 이하에서는 도구 줄 전체 아래에 열린다. 전에는 320px에서 메뉴 왼쪽이 화면 밖으로 잘렸다.
- **공개 알약:** 44px 버튼 안의 28px 칩이다(선택 면, 6px 모서리, 먹색 500). `공개`는 틸 대신 먹색이고 지구본/자물쇠 아이콘과 글자로 구분한다. 문제는 오류 면과 오류색 글자다. 읽기 줄에서는 `›`를 보이지 않는다. `글 정보` 동작·문구·초점 복귀는 그대로다. 작성기의 알약도 같은 칩을 쓴다(공유 부품).
- **글 정보(알약이 여는 대화상자·시트):** 8px 모서리(760px 이하 시트는 위쪽만), 계약의 그림자, 제목 600, 닫기 아이콘은 보조색. `공개하기`와 시트 안 `다시 시도`는 `내 글로 돌아가기`와 같은 틀(입력 테두리색 1px, 6px)이다. 내용·문구·동작은 그대로다.
- **본문:** 제목(28px 700, 자간 -0.01em) 바로 아래가 본문이다. 사이에 아무것도 없다. 작성기 제목도 같은 자간이다.
- **글 끝 줄:** 1px 선 → 날짜(`updatedAt`, 13px 메타색) · `숨긴 글`/`초안`(보조색 500) → 저장 상태(`#photoServerStatus`, `role=status`, 문제일 때만 보임)와 `다시 시도`(먹색 600 + 밑줄, 44px) → `내 글로 돌아가기`(44px, 입력 테두리색 1px, 6px).
- **글 안 링크(읽기·작성기):** 팔레트 밖 파랑 `#3156D3` → 먹색 + 옅은 밑줄(`rgba(55,53,47,.4)`, 4px 띄움). W1 보고가 W3로 넘긴 항목이다.

## 시안·계약과 다른 점 (의도한 것, 판단이 필요한 것)

- **줄 높이 65px(데스크톱).** 공통 머리줄 규칙은 44px이지만 읽기는 "D1 배치 유지"다. 작성기 줄(64px + 선)과 높이가 같아야 읽기 ↔ 편집에서 제목이 움직이지 않고, `minor-defects-ui`가 이를 단언한다. 작성기 줄을 낮추면 함께 낮출 수 있다(작성기는 이번 범위 밖).
- **줄 폭은 680px 읽기 열.** 시안은 본문 영역 전체 폭이다. 틀 폭(`.life-app` 768px)은 `ui.css` 소관이라 손대지 않았다. `뒤로`·경로는 본문 왼쪽 선(500px)에서 시작한다.
- **저장 상태는 평소에 보이지 않는다.** 시안 그림의 `저장됨 · 계정에 올림` 줄은 11-16 소유자 지시로 화면 읽기 프로그램에만 알린다. 그 자리(한 줄 높이)는 v222처럼 비워 둔다.
- **사진 설명은 가운데 정렬 그대로다.** 시안은 왼쪽 정렬이지만 계약 문장에 없고 작성기와 같은 규칙이라 두었다.
- **숨긴 글과 문제 알약은 좁은 화면에서 두 줄.** 위 실측 참고. `목록에 다시 보이기`를 아이콘으로 줄이려면 Lucide 아이콘(`eye` 등) 추가가 필요하다(W1 방식의 vendor 추가, 이번 범위 밖).
- **공개 여부를 모를 때 360px 미만:** 알약에 아이콘이 없으므로(`글 정보`·`공개 확인 못 함`) 글자를 유지한다. 비공개로 보이면 안 되기 때문이다.
- **링크 밑줄 대비 2.21:1.** 위 대비 절.

### 남긴 판단 (작성기 전용, Designer 확인 필요)

`photo-post.css`는 W3 파일이지만 아래는 글 읽기 화면에 나오지 않아 바꾸지 않았다. W5는 "W1–W4 밖의 CSS"만 맡으므로 빠지지 않게 적는다.
