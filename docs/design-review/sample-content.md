# 디자인 비교용 공통 자료

이 자료는 화면 비교와 브라우저 검증을 위해 새로 쓴 익명 예문이다. 실제 사용자 기록, 계정, 가져오기 결과가 아니다. 날짜·제목·원문·출처 구성은 모두 시안용이며 외부 게시물에서 인용하지 않았다. 세 시안은 같은 자료를 사용한다.

원본은 [sample-data.js](../../assets/design-review/sample-data.js)이며 일반 `<script>`로 읽으면 `globalThis.HaedoDesignData`를 제공한다. 이 파일은 저장소 API나 네트워크를 호출하지 않는다. 출처 URL은 실제 서비스로 연결되지 않는 `example.invalid` 예시 주소다.

## 사용 계약

| 필드 | 의미 |
| --- | --- |
| `sources` | 화면 표시 순서를 가진 자료 12건. 원문과 배열은 동결한다. |
| `sources[].id` | `source-01`부터 `source-12`까지의 시안 내부 식별자. |
| `title` | 원문 제목. 화면 폭 때문에 데이터를 잘라 저장하지 않는다. |
| `origin`, `originLabel` | 출처 종류의 코드와 표시 이름. Apple 메모·Obsidian·네이버 블로그·인스타그램 각 3건. |
| `importedLabel` | 가져온 시점 표시. 원문 작성일을 대신하지 않는다. |
| `dateLabel` | 원문 작성일 표시. 확인하지 못한 경우 `작성일 모름`. |
| `version` | 원문 버전의 표시 이름. `source-08`은 같은 출처의 이전 버전이다. |
| `coverage` | `full`은 전체 본문, `partial`은 본문 일부, `link`는 링크만 있음. |
| `topic` | 비교 화면에서 사용한 임시 주제. 실제 분류나 자동 추론 결과가 아니다. |
| `summary` | 시안 작성자가 쓴 짧은 설명. 원문 발췌로 표시하지 않는다. |
| `paragraphs` | 원문 문단 배열. 링크 전용 자료는 빈 배열이다. |
| `url` | 예시 출처 주소. 같은 원문의 두 버전은 같은 주소를 가진다. |
| `excerpt` | 첫 자료의 두 번째 문단에 실제로 포함된 선택 문장. |
| `topics` | 시안에 사용하는 주제 4개. |

첫 자료는 **다시 읽고 싶은 문장을 모으는 방법**이며 원문 8문단을 포함한다. 공통 발췌는 다음 문장이다.

> 기록을 남기는 것보다 다시 만날 수 있게 만드는 일이 더 중요했다.

실제 시안은 제목·원문에서 `기록`을 찾는 공통 검색 상태로 비교하며 11건이 일치한다. `summary`는 누락 범위 설명 등에 쓰는 시안 메타정보이며 본문 검색이나 원문 인용에 포함하지 않는다. 검색 결과 수는 실제 필터 결과로 표시하고, 임의의 성과 지표를 만들지 않는다.

## 포함한 비교 조건

- `source-05`: 공백 포함 80자 이상인 긴 제목. 모바일 줄바꿈과 목록 밀도를 비교한다.
- `source-04`, `source-09`: 작성일 모름. 가져온 날짜와 원문 작성일을 구분한다.
- `source-03`, `source-04`, `source-11`, `source-12`: 본문 일부만 있음. 포함하지 않은 사진·댓글·나머지 문단을 확보한 것으로 표시하지 않는다.
- `source-09`: 링크 전용 자료. 읽을 본문이 없으므로 원문 발췌를 제공하지 않는다.
- `source-01`, `source-08`: 같은 원문의 최근 버전과 이전 버전. 이전 자료를 중복 오류로 숨기거나 최신 본문으로 덮어쓰지 않는다.
- 서로 다른 길이의 제목·원문·설명: 실제 내용을 읽을 때의 위계와 줄 길이를 비교한다.

많은 자료·빈 결과·로딩·오류 상태는 시안 화면에서 명시적으로 선택하는 검증 상태로 만든다. 많은 자료를 표현하기 위해 예문을 반복한다면 화면에 확장 예시임을 알리고, 각 반복 항목에는 고유한 시안 식별자를 부여한다. 공통 원본 배열을 바꾸거나 실제 저장 데이터에 넣지 않는다.

브라우저 크기 비교는 실제 Apple 기기의 터치·한글 입력·파일 선택 검증과 구분한다. 이 예문이 보이는 스크린샷을 사용자 개인 자료로 설명하지 않는다.
