# 추천 콘텐츠 언어와 관련 표현 연결

2026-10-22 KST. 기준 main `a0eac63`/SW155에서 기존 뉴스 설정·수집기·추천기·읽기 비교를 재사용한다. 목표는 **주제 입력 → 콘텐츠 언어 복수 선택 → 정확한 이유로 후보 확인 → 원문/명시 번역 → 같은 조건의 읽기 비교와 재열기**다. 새로운 검색 서버·모델·계정 연결을 추가하지 않는다.

## 언어 선택과 화면

콘텐츠 언어는 기존 한국어·영어·일본어·중국어·스페인어·프랑스어·독일어 및 미확인/혼합/기타 분류를 유지한다. `null`은 전체, `[]`는 선택 없음이며 선택한 언어의 합집합을 최신순·관심순·개인 추천 후보와 과거 좋아요 근거에 먼저 적용한다. BCP47 지역 표기는 기존 기본 언어 규칙을 사용하고 원문 메타데이터를 다시 쓰지 않는다.

뉴스 설정의 기존 언어 옵션에 복수 선택 범례와 현재 선택 요약을 붙인다. 접힌 요약은 최대 세 언어와 나머지 수, 접근 가능한 이름은 전체 선택 언어를 제공한다. 미저장 선택·실패·CAS 충돌과 초점을 보존하며 기본 피드에 설명 행을 추가하지 않는다. 활성 출처에 글이 있지만 선택 언어와 교집합이 없을 때만 기존 빈 결과 한 줄을 언어 공급 부족으로 구분한다. 선택 없음·출처 모두 끄기·주제 불일치·공급 오류를 같은 원인으로 표시하지 않는다.

번역해서 열 언어는 독립적인 한 대상이다. 여러 콘텐츠 언어를 고른 뒤 번역 대상을 변경하거나 끄더라도 콘텐츠 선택은 유지된다. 번역 링크는 명시 클릭 때 공개 원문 주소를 전달하며 자동 번역·본문 저장·주제 번역을 하지 않는다. 현재 운영 공급 언어와 선택 가능한 언어는 별개다. 일본어·중국어·프랑스어를 선택할 수 있다는 사실이 해당 언어의 현재 기사 확보를 뜻하지 않는다.

## 동의 표현과 방향성 관련 표현

좁은 직역/음역만 기존 동의 표현에 추가한다. 일반적인 reading·attention·concentration·persistence를 같은 뜻으로 묶지 않는다. grit의 동음이의어를 구별하는 의미 모델은 아니다.

추가적인 관련 표현은 **명시한 주제 → 제목의 좁은 표현**이라는 방향을 둔다. 외국어 학습의 구체적인 학습 명사구, 독서의 reading comprehension, 집중력의 sustained attention/mind wandering/minds wander 등이다. 관련 표현을 입력했다고 상위 주제나 다른 관련 표현으로 역방향·연쇄 확장하지 않는다. 공식 태그나 개인 좋아요의 표현 확장에도 사용하지 않는다. 같은 제목 구간은 직접/동의 표현을 우선하며 관련 표현이 여러 개라는 이유로 점수나 독립 근거를 부풀리지 않는다.

출력은 실제 제목의 UTF-16 위치·인용·원래 입력 주제를 보관하고 `via=related`를 기존 근거 줄에서 **관련 표현**으로 표시한다. 동의어·자동 취향 학습·실독 후 도움으로 표시하지 않는다. 어휘 도달성의 변화와 사용자가 실제로 도움을 받은 결과를 구분한다.

공유 별칭은 개인 추천의 단일 표현 정규화에도 영향을 주므로 정책을 `public-title-tag-expressions-v4`로 명시한다. 최소 두 표현·명시 opt-in·좋아요만 근거로 쓰는 조건은 유지한다. 실제 과거 모듈로 생성한 v3와 기존 v2 비교는 당시 제목·이유·판단 그대로 열고 수정·삭제하며, 현재 추천기로 재계산하거나 답을 새 후보로 옮기지 않는다. 저장 형식은 바꾸지 않는다.

## 심리학 연구 공급

[Frontiers in Psychology 공식 RSS](https://www.frontiersin.org/journals/psychology/rss)의 제목·링크·첫 작성자·발행일만 추가한다. [공식 저작권 조건](https://www.frontiersin.org/journals/psychology/about#copyright-statement)에서 CC-BY와 출처표시·변경명시 조건을 확인했으며 확인하지 않은 버전 번호는 적지 않는다. 제3자 자료·별도 고지 예외가 있고 초록·본문·이미지는 수집하지 않는다.

기존 표준 XML 파서와 호스트/robots 검증을 재사용한다. 이 출처의 소문자 `pubdate`만 명시적으로 대응하고 표준 날짜 필드의 우선순위와 unknown/future 처리는 유지한다. 반복 작성자 중 첫 작성자만 보관한다. OriginalResearch/Review 등의 category는 논문 유형이므로 주제 태그로 쓰지 않는다. 실패하면 이전 메타데이터를 오래된 상태로 보존한다.

광범위한 심리학 최신 피드 하나가 모든 관심의 연구·실용 조언을 충분히 공급하지는 않는다. PsyPost는 공식 약관 본문을 확인하지 못해 제외했고 APS는 확인한 공식 홈페이지에서 RSS 선언을 찾지 못해 제외했다. 기존 수집기와 랭커를 재사용하는 편이 새 검색/추천 서비스를 도입하는 것보다 이번의 명시 필터·정확 근거·작은 공개 공급에 적합하다.
