# 글의 흐름을 읽고 회고 원고 남기기

2026-10-08 KST. 사용자 목적은 20대의 글을 돌아보며 자신과 생각의 흐름을 이해하고, 나중에는 나이와 무관한 특정 주제의 책으로 엮는 것이다. [전체 설계와 후속 단계](../life-tools-design/reflection-book.md)를 새 최우선으로 삼았다.

## 첫 사용 단위

**도구 → 회고 → 돌아볼 원문 선택 → 연도별/주제별 읽기 → 내 회고 작성 → 원고 파일로 보관**한다. 기존 회고문과 선택은 그대로 유지한다. 이전의 원문 개수 집계에 읽기·질문·원고 내보내기를 더했으며 자동으로 사용자 성격이나 삶의 성과를 평가하지 않는다.

선택한 정확 버전을 작성 연도별로 보여주며 같은 연도 안에서는 선택순을 유지한다. `YYYY`, 유효한 `YYYY-MM`, 유효한 날짜·ISO 날짜시각만 분류하며 시간대를 바꿔 작성 연도를 이동시키지 않는다. 미상·자유 형식·잘못된 날짜·연결이 없는 버전은 ‘작성 시기 미확인’으로 남긴다. 가져온 시점을 경험일이나 작성일로 대신 쓰지 않는다. 선택하지 않은 해를 채워 실패나 결핍처럼 표시하지 않는다.

‘작성 연도로 좁히기’는 이번 화면의 보기 조건이다. 후보 목록과 선택한 글의 표시 범위를 좁힐 뿐, 선택 원문이나 회고문을 지우지 않는다. 미확인 자료는 기간을 적용해도 보인다. 실제 20대 기간·나이 계산을 추정하지 않는다. 보기 기간은 새로고침/다른 기기/백업에 저장되는 프로젝트 설정이 아니다.

주제별 보기는 사용자가 이미 만든 묶음과 선택한 정확 버전의 교집합이다. 묶음에 다른 글이 있어도 회고에 자동 포함하지 않는다. 주제를 자동 추론하지 않으며, 아직 묶지 않은 글도 따로 남긴다. 주제 묶음은 기록에서 편집한다. 본문은 명시적으로 펼칠 때 읽고, 책 아이콘으로 원문을 열면 현재 입력을 보관한 뒤 정확 버전으로 이동한다. 돌아올 때 해당 조작의 초점과 스크롤을 복구한다.

현재 생각은 기존 ‘내 회고’에 작성한다. ‘시간순 돌아보기’, ‘주제별 돌아보기’, ‘책의 목차 구상’을 누르면 질문을 **기존 메모 뒤에 추가**한다. 몰래 텍스트를 대체하거나 기계용 상태를 회고문에 숨기지 않는다. 당시 글·타인의 참고글·현재 해석을 구분하며 근거와 맞지 않는 기억이나 반대 사례도 남길 수 있다. 이 질문들은 AI가 실제 자료를 분석한 결과가 아니다.

## 원고와 보존

Markdown은 기본적으로 현재 회고와 **선택 전체의 출처**를 담는다. 화면에 적용한 연도 조건 때문에 선택 원문을 몰래 제외하지 않으며 UI에도 그 범위를 안내한다. ‘선택한 원문 본문도 포함’을 명시적으로 켜야 전체 본문을 함께 담는다. 타인 글·작성자 미확인·부분 본문·링크만 보관·누락을 구분한다. 원형 메타데이터와 선택 버전의 CRLF/emoji를 보존하고, 자료 속 Markdown/HTML/URL은 안전한 코드 블록으로 내보내 외부 링크·이미지로 자동 실행하지 않는다. 사용자가 직접 작성한 회고문은 Markdown 원값을 유지한다.

다운로드 전에 저장을 완료하며, 저장 실패나 계정·공간 이탈 때 성공한 파일로 표시하지 않는다. 공개 게시·외부 분석 요청은 없다. Markdown은 편집용 원고이며 복원용 백업은 기존 자료·구성 JSON이다.

기존 `reflection.versionIds`/`note`, 구성 CAS·선택 동기화·백업·공개 모델·연표는 변경하지 않았다. 새 `reflection.js`는 읽기 전용 분류·원고 변환이며 원문을 수정하지 않는다. 기존 라이브러리·네이티브 details/textarea/Blob을 재사용한다. 새로운 에디터·조판 의존성은 첫 읽기 단위에 필요하지 않으며, 책 프로젝트와 PDF 단계의 공식 비교 기준은 [설계](../life-tools-design/reflection-book.md)에 남겼다.

합성 계정·익명 한글 자료와 실제 앱·SDK·IndexedDB를 사용한다. 운영 Supabase, 개인 기록, 실제 Google 로그인은 호출하지 않았다. 기능과 시각 판단을 구분해 확인했다.

- 기존 Workbench의 회고 선택/재열기와 잘못된 백업 후보 차단 2/2 통과. 전체 Workbench 검사를 반복한 것으로 보고하지 않는다.
- 신규 [전체 흐름 5/5](evidence/reflection-reading/run-2026-10-08T00-58-57-810Z.json): 세 폭의 정확 원문 선택·기간/주제·메모·Markdown, 잘못된 기간 복구와 실제 IDB 저장 실패, 실제 JSON 다운로드/새 공간 복원 통과.

## 아직 없는 기능과 Local 인계

현재는 작업공간당 회고 한 개이고 회고문 한도는 20,000 UTF-16 단위다. **여러 책 프로젝트·장별 문서·근거가 달린 AI 분석·인쇄용 PDF/책자**는 다음 구현이다. 이 제한을 숨긴 채 긴 책 원고를 현재 메모에 계속 쌓도록 권하지 않는다.

선행 PR #44 다음에 검토할 변경이며 캐시 v78, SQL 설치 없음. Local이 병합·배포·라이브 확인을 담당한다. 실제 Mac/iPad/iPhone의 한글 IME·Files·선택 손잡이·VoiceOver 체험은 Chromium의 세 폭 검사와 별도다.
