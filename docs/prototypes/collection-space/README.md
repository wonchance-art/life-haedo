# 컬렉션 상호작용 시안

실제 앱과 분리된 비교용 화면이다. 가상의 작품명·창작자·표지 18개를 사용한다. 본문·항목·선택은 메모리에만 있으며 새로고침하면 초기화된다. 개인 자료를 입력하지 않는다.

저장소 루트에서 `python3 scripts/dev-server.py --port 4189` 실행 후 같은 컴퓨터의 브라우저에서 경로 `/docs/prototypes/collection-space/`를 연다. Cloud의 loopback 주소는 외부 접속 링크가 아니다. 종료는 서버 터미널에서 Ctrl+C.

1. A/B를 바꿔 같은 자료의 표지 중심 / 메모 중심 배치를 비교한다.
2. 음악·책·도구 필터, 모음 선택, 제목·만든 사람·메모 검색을 사용한다.
3. 항목을 열어 메모를 바꾸고 Escape로 돌아온다.
4. 연필 → 컬렉션에서 고르기 → 앨범·책·도구 선택 → 글에 연결. 선택 취소와 연결 해제도 체험한다.
5. 더하기에서 표지 없는 항목을 직접 입력한다. 실제 저장이 아니다.
6. 아래 시안 검토 도구에서 126개, 로딩, 오류를 살핀다. 오류의 다시 시도는 상태 모사다.

자동 메타데이터·외부 이미지·YouTube iframe·계정·IndexedDB·동기화·공개·백업은 연결하지 않았다. CSP도 외부 연결/프레임/폼 전송을 막는다. 제목·메모를 HTML로 해석하지 않는다.

검증: `BASE_URL=http://127.0.0.1:4189 node tests/collection-space-prototype-browser.cjs`.
필요 시 기존 설치의 `PW_MODULE_PATH`, `CHROMIUM_PATH`를 지정한다. 운영 앱에 새 패키지를 설치하지 않는다.

후속 [취향 페이지 편집 시안](../taste-page/README.md)에서 3가지 배치와 색·여백·내용 커스터마이징을 확인한다.

2026-10-12: 예술 작품 유형을 추가했다. 회화·사진 가상 자료와 세로/가로 이미지 미연결 표시를 제공한다. 보관함의 직접 입력에서는 작가·제작 연도·재료·소장처·출처 주소를 입력할 수 있다. 취향 페이지의 파일 보관은 가상 작품 ID를 포함하며 보관함에서 직접 추가한 임시 자료와 아직 공유되지 않는다. 실제 작품 이미지·자동 정보 조회는 미연결이다.

영화는 일반 영상과 별도 유형이다. 감독·개봉 연도·국가·상영시간·출처를 기록하며 포스터 미연결 상태를 2:3 비율로 보여준다. 실제 포스터/예고편/자동 정보 조회는 미연결이다.

인물도 독립 유형으로 선택한다. 이름·활동 분야·출처와 좋아하는 이유(비공개 메모)를 구분하며 실제 사진/약력 자동 조회는 없다. 인물의 활동 분야를 다른 자료의 작성자로 저장하지 않는다. 작품·감독 정보와 인물 항목의 자동 연결은 후속이다.
