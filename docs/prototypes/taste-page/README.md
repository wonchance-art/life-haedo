# 취향 페이지 · 브라우저 시안

2026-10-11. 독립 HTML/CSS/JavaScript 시안이다. 14개 가상 자료를 고르고 배치해 페이지를 만들고, 시안 파일로 보관·다시 열 수 있다. 운영 내 페이지나 계정별 자료 저장은 아니다. 표지는 AI 생성 가상 이미지다.

저장소 루트에서 `python3 scripts/dev-server.py --port 4189`로 시작한다. 같은 컴퓨터에서 경로 `/docs/prototypes/taste-page/`를 연다. Cloud loopback은 외부 접속 링크가 아니다. 기존 `/docs/prototypes/collection-space/`의 **내 페이지 꾸미기**에서도 들어간다.

1. **꾸미기**에서 배치·제목·소개·내 문장·색·여백을 조절한다. 편집창 옆/위의 결과도 스크롤해 볼 수 있다.
2. **자료 구성**에서 섹션 이름을 바꾸고 자료를 추가·제외하거나 화살표로 순서를 바꾼다. 제외는 원본 삭제가 아니다. 두 섹션의 구성은 독립적이다.
3. **미리보기**는 비공개 결과다. 항목 상세에는 자료의 비공개 메모를 넣지 않는다. **편집으로**에서 돌아온다.
4. **되돌리기**는 텍스트 필드에 들어가 수정하고 빠져나오는 한 편집을 묶어 되돌린다. 배치·추가·제외·초기화·파일 열기도 되돌린다. 최근 80개 편집을 페이지 메모리에 보관한다.
5. **시안 파일 → 파일 내려받기**를 누르고 실제 파일 보관을 확인한다. 새로 열었을 때 **시안 파일 열기**로 복원한다. 제목·내 문장·스타일·섹션 이름·가상 자료 ID만 포함한다. 자료의 비공개 메모·원문·계정은 포함하지 않는다. 해도 자료 백업과 별개다.
6. 잘못된 파일·모르는 자료 ID·32KB 초과 파일은 거절하고 현재 편집을 유지한다. 파일을 읽는 동안의 새 편집도 덮어쓰지 않는다.

자동 저장은 없다. 변경 후 이동/새로고침에는 브라우저 이탈 경고를 요청하지만 기기·브라우저가 항상 이를 보장하지 않는다. 파일을 내려받지 않으면 탭 종료 후 복구할 수 없다. 파일 다운로드 요청을 디스크 저장 완료로 표시하지 않는다.

운영 데이터·Auth·IndexedDB·동기화·공개 API·YouTube·외부 요청을 연결하지 않았다. 커버/콘텐츠 업로드가 아니라 시안 구성 JSON만 다시 여는 기능이다. 공개 권한 변경은 없으며 새 의존성도 없다.

검사: `BASE_URL=http://127.0.0.1:4189 node tests/taste-page-prototype-browser.cjs`. 기존 설치를 쓰려면 `PW_MODULE_PATH`/`CHROMIUM_PATH`를 지정한다. 증거를 별도로 남기려면 `TASTE_PAGE_OUTPUT=.local/taste-page-review`를 지정한다.

2026-10-12: 예술 작품 유형을 추가했다. 회화·사진 가상 자료와 세로/가로 이미지 미연결 표시를 제공한다. 보관함의 직접 입력에서는 작가·제작 연도·재료·소장처·출처 주소를 입력할 수 있다. 취향 페이지의 파일 보관은 가상 작품 ID를 포함하며 보관함에서 직접 추가한 임시 자료와 아직 공유되지 않는다. 실제 작품 이미지·자동 정보 조회는 미연결이다.
