# 표지 이미지 출처

`cover-studies.png`는 2026-10-11 이번 시안을 위해 image_gen으로 생성한 가상 이미지다. 실제 앨범/책 표지나 참고 사이트에서 받은 이미지가 아니다. 원본은 `/workspace/generated_images/exec-81720bab-a22e-4d3e-a127-1148babd29c9.png`에 보존했다. 네 개 사각형을 한 장으로 생성했고 파일은 그대로 복사했다. UI의 CSS background-position이 각 사각형을 표시한다. 웹에 외부 이미지 요청을 보내지 않는다.

- 왼쪽 위: 물결, 가상 앨범 ‘느린 저녁’.
- 오른쪽 위: 주황 커튼, 가상 앨범 ‘창가에 남은 빛’.
- 왼쪽 아래: 금속·파란 유리, 가상 책/앨범의 디자인 비교.
- 오른쪽 아래: 식물·노란 꽃, 가상 책 ‘일상의 작은 발견’.

글자는 브라우저 DOM으로 얹는다. 실제 작품 메타데이터로 재사용하거나 라이선스가 확인된 실물 커버라고 표시하지 않는다. 운영 공개 산출물의 allowlist에 포함하지 않았다.
