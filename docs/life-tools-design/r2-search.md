# R2 검색에서 일치한 원문으로 돌아가기

2026-10-03 · 확정 자료의 검색 → 일치한 버전·문맥 확인 → 원문 발췌 → 검색 목록 복귀 단위의 로컬 구현·통합 검증 완료. 원천별 전체 형식 지원·자동 수집·AI 검색은 후속 범위다.

## 사용 장면

Apple 메모·Obsidian·네이버 블로그·인스타그램에서 사용자가 제공해 보관한 자료 중 기억나는 구절을 찾는다. 예를 들어 원문 버전 1에 `씨앗`이 있고 새 버전 2에서는 빠졌다면, 검색 결과는 버전 1의 일치 문맥을 보여주고 **버전 1의 실제 위치**를 연다. 그 구절을 선택해 주제에 추가하면 발췌의 출처도 버전 1을 참조한다. 최신 버전으로 조용히 바꾸거나 과거 원문을 덮어쓰지 않는다.

## 결과와 버전의 의미

| 경우 | 결과와 원문 열기 |
| --- | --- |
| 본문에만 일치 | 일치한 버전마다 한 결과를 보여준다. 해당 버전의 첫 일치 구절과 짧은 앞뒤 문맥을 표시하고 그 위치를 연다. |
| 현재 제목에만 일치 | 최신 버전을 한 번 보여주고 `제목 일치 · 본문 일치 없음`을 표시한다. 본문 일치 좌표·인용·문맥은 만들지 않고 이전 선택을 검색 일치처럼 강조하지 않는다. |
| 과거 본문과 현재 제목에 일치 | 본문이 일치한 버전과 제목 때문에 포함된 최신 버전을 함께 보여준다. 같은 버전이 양쪽에 해당하면 한 결과로 합치고 실제 본문 일치를 우선한다. |
| 여러 본문 버전에 일치 | 버전별로 구분해 원하는 버전을 직접 연다. 같은 버전 내 반복 구절을 전부 별도 결과로 세지 않는다. |
| 링크만 보관한 자료 | 제목이 일치하면 결과에 나타날 수 있다. 본문 미확보 상태를 유지하며 본문 문맥·발췌 기능을 제공하지 않는다. 외부 본문을 가져오지 않는다. |
| 검색어 없음 | 원천별 최신 버전을 보여주는 기존 목록을 유지한다. |
| 지정한 원문 버전이 없어짐 | 찾을 수 없음을 표시하고 목록으로 돌아가도록 한다. 최신 버전을 대신 열지 않는다. |

결과의 `자료 읽기`는 해당 버전을 연다. `버전 N/총수 · 최신 버전/이전 버전`과 `본문 일치` 또는 제목 일치를 구분해서 표시한다. 제목은 현재 자료의 제목이며 과거 버전별 제목을 복원한 것이 아니다. 버전 번호는 보관 순서이고 마지막 버전이 최신이다. 가져온 시각을 원작성일·실제 경험일로 대신하지 않는다. 같은 자료 안에서는 일치한 최신 버전부터 보여주며 관련도 순위를 추정하지 않는다.

검색 문맥은 받은 원문 문자에서 얻고 실행하지 않는다. 한글·emoji·CRLF가 있어도 원문 구간과 인용이 맞아야 한다. 결과를 연 뒤 수동으로 버전을 바꾸면 이전 버전의 검색 좌표를 새 본문에 적용하지 않는다. 기존 발췌 저장 로직을 사용하므로 검색하거나 발췌한다고 새 원문 버전을 만들지 않는다.

## 검색 범위와 목록 복귀

- 현재 계정·작업공간의 **확정한 원천 제목과 보관 본문**을 찾는다. 미적용 검토 초안·아직 읽지 않은 파일·첨부·이미지·원천 서비스의 웹 자료는 검색하지 않는다.
- 검색어는 최대 500 UTF-16 단위다. 양끝 공백을 제외하고 입력한 문자열 그대로 찾으며, `.`·`*`·`[` 같은 문자를 정규식 명령으로 실행하지 않는다.
- 본문 검색은 JavaScript의 문자 그대로 찾기와 `/iu` 대소문자 구분 없는 일치를 사용한다. 퍼지 검색·어간·띄어쓰기 추정·NFC/NFD 정규화 동등 비교는 지원하지 않는다. 같은 글자로 보이는 Unicode 조합이 달라도 서로 일치한다고 보장하지 않는다.
- 원천 검색의 검색어·원천 필터와 모아보기의 검색어·주제 필터를 각각 유지한다. `검색 결과로 돌아가기`는 해당 목록의 조건·스크롤·가능한 결과 버튼의 포커스를 복원한다. 결과가 없어진 경우에는 검색 입력으로 돌아간다. `검색어 지우기`로 검색만 해제할 수 있다.
- 모아보기 발췌가 여러 원문을 참조하면 연결된 출처 제목을 검색하고, `원문에서 보기 · 출처명`으로 출처별 해당 버전·구간을 열 수 있다. 첫 출처로 자동 바꾸지 않는다.
- 검색어와 복귀 위치는 화면 메모리에만 둔다. URL·방문 기록·저장소·네트워크·백업·기기 간 동기화에 검색어를 넣지 않는다. 작업공간·계정 전환이나 화면 폐기 시 초기화하며 새로고침 복구를 약속하지 않는다.
- 입력 중 결과 갱신으로 포커스를 빼앗지 않는다. 한글 등 조합 입력은 조합 완료 후 최종 값으로 검색한다. 실제 Apple 키보드·IME 체험은 별도 확인한다.

## 직접 확인

```sh
npm run check
npm test
npm run dev
```

`http://127.0.0.1:4173/life.html`의 개인 화면에는 [공용 인증 설정](../platform.md)이 필요하다. 실제 Google 제공자 로그인과 익명 테스트의 모의 인증은 구분한다. 로컬 변경은 공개 배포 전까지 사이트에 반영되지 않는다. 서버 종료는 실행 터미널에서 `Ctrl+C`다.

1. 익명 본문 `봄의 씨앗을 다시 읽는다.`를 자료만 보관한다. 같은 제목·검증용 원문 링크를 사용해 `봄의 질문을 다시 읽는다.`를 가져오고 같은 원천의 새 버전을 명시적으로 선택해 버전 1·2를 준비한다.
2. `원천 기록`에서 `씨앗`을 검색한다. 버전 1의 일치 구절·문맥·버전 표시가 나타나는지 확인하고 해당 결과를 연다. 버전 2를 대신 열면 안 된다.
3. 버전 1의 구절을 직접 선택해 주제를 붙이고 기존 발췌 기능으로 저장한다. 발췌의 출처에서 버전 1 원문·선택 구간을 다시 확인한다.
4. `검색 결과로 돌아가기`로 검색어·원천 필터·결과 위치가 유지되는지 확인한다. 모아보기에서도 주제와 검색어를 고른 뒤 발췌의 원문을 열었다가 조건을 유지한 목록으로 돌아온다.
5. 제목만 일치하는 자료, 제목이 있는 링크 전용 자료, 여러 버전에 같은 구절이 있는 자료를 확인한다. 제목 일치를 본문 일치로 표시하지 않고 링크 자료에 본문을 만든 것처럼 보이지 않아야 한다.

브라우저 검사 합계 60/60 통과이며 예상 밖 console/pageerror는 0개다. 의도한 실패 복구 console 오류는 기존 자료/동기화/플랫폼 검사에서 각각 1/7/1개로 별도 집계했고 새 검색 검사에는 예상 밖 오류가 없었다. 최종 검색 재검증에는 제목만 일치할 때 이전 선택을 억제하고 지정 버전이 없을 때 최신으로 대체하지 않는 추가 assertion도 포함했다.

이번 검증은 익명 샘플을 사용하며 새 운영 DB 행·SQL·저장 스키마·백업 형식·인증 변경을 추가하지 않았다. SQL 재설치도 필요하지 않다. Chromium 크기 모사와 모의 HTTP는 Apple 실기·Google OAuth·실서비스 권한 검증을 대신하지 않는다.

변경은 [초안 PR #19](https://github.com/wonchance-art/life-haedo/pull/19)로 검토하며 기존 PR #17을 기준으로 한다. API 접근 문제는 해결됐지만 Google 제공자는 실제 조회에서도 비활성 상태다. 실제 Apple 체험·Google 외부 설정과 로그인·기존 익명 8행의 관리자 정리·공개 배포는 남아 있다.
