정리 기준: 02 October 2026 (Asia/Seoul). 공개용 설계 파생본이며 전체 대화 원문이 아니다.

## 최신 요청과 상태 확인

사용자가 문서 보관에 이어 **PR #18을 병합하고 이 대화를 마무리**하도록 명시적으로 요청했다. 따라서 앞선 '별도 브랜치 보관만 허용, main 병합 미승인' 범위는 이번 문서 PR의 병합에 한해 갱신됐다. 실제 병합 여부와 병합 커밋은 [PR #18](https://github.com/wonchance-art/life-haedo/pull/18)에서 확인한다. 이 문장은 실행 전 작성한 승인 기록이지 병합 성공을 미리 선언하는 문장이 아니다.

이번 변경은 공개용 참고 문서 6개와 기존 Mermaid 도식 2개다. 기존 AGENTS.md·CLAUDE.md·Skills·Codex 설정·앱 코드·의존성·DB·인증·배포 설정은 변경하지 않는다. 문서가 main에 들어가도 새로운 앱 기능·AI 자동화·개발 제안 규칙이 자동 설치되는 것은 아니다. 기존 Pages 설정이 main 변경에 반응해 실행될 수 있으나, 배포 설정 변경이나 신규 기능 배포는 범위가 아니다.

기준 코드는 `ec32d0fcd6fbd316186a4df4a8e4f4c4da0fc284`, 최초 문서 보관 커밋은 `eaf13d7de50e7b16eff82fee2d2b92bd1d92db30`이다. 다른 미병합 PR이나 과거 디자인 시안은 이번 병합에 포함하지 않는다.

## 기존 구현과 새 구상의 관계

기준 커밋의 문서·코드에서 확인한 기존 앱은 사건·기간·생각, 연표·목록·검색, 로컬 저장·백업·사본 복원·실행 취소, 선택적 DB 동기화를 갖춘 정적 앱이다. 새 서재·AI 운영센터·다중 사용자 플랫폼이 이미 구현됐다는 뜻은 아니다.

연표는 활동을 시간으로 보는 도구로 유지하는 방향을 검토했다. 책의 판본·목차·문제 풀이를 모두 사건 데이터에 넣지 않고, 서재 활동과 연표의 구체적인 연결은 해당 기능을 다룰 때 설계한다. 같은 repo에 들어왔다는 이유로 기존 앱을 전면 재작성하지 않는다.

기존 리뷰의 운영 DB 권한 미검증, 모의 응답 동기화 검사, 로컬 검증과 배포 확인의 차이는 남아 있다. 이번 문서 검토·병합은 새로운 앱 실행·계정 격리 검증 결과가 아니다. v2의 알려진 빈칸은 design.md의 O-01~O-09를 참조한다.

## 공개 자료와 비공개 백업

공개본에는 목적·제약·이유·판단의 변화는 남기고, 실명·연락처·생활 장소·정확한 근무표·사적 친구 정보·자격증명·개인 DB 설정은 포함하지 않는다. 전체 대화와 생성 이미지는 이 repo에 올리지 않았다.

CTX-*는 이 묶음에서 만든 논점 표지이며 실제 채팅 메시지 ID가 아니다. 비공개 대응표나 별도 비공개 저장소를 생성한 것은 아니다. 공개 파생본만으로 모든 대화 문장을 복원할 수 없다.

채팅을 삭제하기 전, 이전에 만든 대화 TXT·이미지 묶음과 최종 보충 인계 자료를 사용자 기기에 별도로 보관하는 것이 권장된다. 이전 TXT는 작성 당시까지의 기록이며, 그 후 대화까지 자동으로 덧붙여진 파일은 아니다. 스냅샷과 최신 판단 요약을 구분하고 개인정보가 담긴 백업 ZIP을 공개 저장소에 업로드하지 않는다.

첫 업로드안은 도구 안전 검사에서 차단됐고 정확한 사유는 미확인이다. 이후 기존 지침 파일을 바꾸지 않는 문서 보관안으로 PR #18을 만들었다. 이 이력에서 차단 원인을 추정해 확정하지 않는다.
