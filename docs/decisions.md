## 이전 전달 시도의 기록

첫 업로드 요청은 도구 안전 검사에서 차단됐고 구체적 사유는 제공되지 않았다. 이를 설계 내용이 잘못됐다는 검증 결과나 AGENTS.md가 원인이었다는 증거로 취급하지 않는다. 이후 지침 파일 수정 없이 문서만 추가하는 범위로 PR #18을 만들었다. 병합의 실제 결과는 GitHub PR 상태·커밋으로 확인한다.

## 해석 규칙

공개 서재·친구별 큐레이션처럼 사용자가 좋아한 방향을 없던 것으로 만들지 않는다. 다만 최신 필요 우선 원칙에 따라 초기 필수 구현 목록으로 묶지 않는다. [제안 목록](proposals.md)을 함께 본다.

AI가 제안한 전체 구조와 승인·복구 도식은 참조 자료다. 사용자 검토·강화 요청이 모든 내부 구현 선택의 확정이나 실제 안전성 검증을 뜻하지 않는다.

후속 결정에는 무엇을 바꾸는지, 이유·근거, 사용자 발언과 AI 가설의 구분, 이전 판단의 대체 여부, 실행 권한을 남기는 방식을 제안한다. 이전 기록은 보존하며, 실제로 저장한 내용과 아직 제안만 한 내용을 구분한다. 이번 병합 허가는 후속 기능 구현이나 전체 설정 적용으로 확대 해석하지 않는다.
