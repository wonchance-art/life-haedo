# 현재 기준 — 필요 우선, 확장은 선택

기준: 02 October 2026 (Asia/Seoul). 제품 방향을 복원하는 보관용 문서이며 작업 일정표나 실행 지침의 자동 적용이 아니다. 이번 변경은 참고 문서 추가만 대상으로 하며 기존 AGENTS.md와 앱·설정은 그대로 유지한다.

## 상위 원칙

사용자가 일상에서 실제로 필요한 기능을 집중해서 만든다. 그 방향에서 작은 변화로 가능한 재사용·공유·다른 활동·플랫폼화를 적극적으로 제안하고, 사용자가 선택하면 확장한다. 처음부터 완성형 플랫폼을 필수 조건으로 규정하지 않는다.

## 현재 확인된 필요

| ID | 필요 | 의미와 경계 |
| --- | --- | --- |
| N-01 | 일상 기록·관리 | 일정·약속·활동·상태·이어가기 자체로 유용해야 한다. 탐구·발행 아래의 부가기능이 아니다. |

| N-04 | 한 페이지 연속성 | 생활·활동·기록·대화를 오갈 때 대상·진행 맥락을 잃지 않는다. 모든 패널의 동시 노출을 뜻하지 않는다. |

이는 필요의 기록이지 모든 항목의 구현을 승인했다는 뜻은 아니다. 실제 구현 요청 시 해당 범위를 좁혀 적용한다.

## 가장 구체적인 예: 책·교재

제목·ISBN으로 후보를 찾아 판본을 확인한다. 확보한 기본 정보와 목차만 채운다. 없는 정보는 미확보로 남기고 보완 가능하게 한다. 목차·표지를 확보했다고 본문을 읽은 것처럼 답하지 않는다.

이후에는 페이지·단원·문제 풀이·메모 등 달라진 부분만 입력한다. 마지막 위치, 실제 읽은 구간, 재독, 이해, 문제 완료는 다르다. 다시 열면 지난 위치·남긴 질문·다시 볼 곳을 복원한다. 숫자 갱신과 저장은 AI가 실패해도 가능해야 한다.

동일 저자·출판사의 책 둘러보기와 현재 질문 중심 추천을 구분한다. 이미 가진 자료를 다시 발견하도록 돕는다. 일상 기록과 서재의 동일 활동을 중복 입력하지 않는다.

## 이번 보관 요청의 범위

공개 가능한 참고 문서와 기존 도식을 별도 브랜치에 보관한다. 루트 AGENTS.md·CLAUDE.md·Skill·Codex 설정은 수정하지 않는다. 개발 제안 규칙은 검토용 문서로만 남긴다.

앱 코드·의존성·DB·인증·배포 설정, 실데이터 이전, 유료 API·예약 실행, 다중 사용자 전환, 자동 발행·전송, main 병합·배포는 이번 요청에 포함되지 않는다. 이후 명시적인 사용자 요청이 범위를 갱신할 수 있다.

## 유지할 구분

- 제안 / 사용자가 좋아한 방향 / 설계 채택 / 구현 허가 / 검증 완료.
- 직접 경험과 사용자 판단 / AI 지원과 추정.
- 예정과 실제 수행 / 원문과 요약 / 사적 기록과 공개본.
- 개인 생활 AI / 개발 에이전트 / 서비스 운영 관리자.
- 범용 기능 / 분야별 규칙 / 필요한 경우의 하위 모듈.

현재 앱의 저장·백업·동기화·화면을 보호한다. 같은 repo를 쓰는 것이 전체 재작성의 근거는 아니다. 채팅→앱→플랫폼, 단일→다중 에이전트는 의무적인 발전 순서가 아니다.

## 미결 사항

첫 구현 범위·순서, 자료 제공처·비용, 활동 단위, 기존 연표와 서재 데이터 연결, 공개·친구 권한, 계정 도입 시점, 자동화 실행 환경·모델, 최종 UI·사업 모델은 확정하지 않았다. 미결 항목 전부를 해결한 뒤에야 생활 도구를 만들 수 있는 구조로 만들지 않는다.
