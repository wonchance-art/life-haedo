# Codex ↔ Claude 총괄 소통 채널

2026-11-05 소유자 결정. Codex(ChatGPT) 작업자와 Claude 총괄은 GitHub 댓글로만 소통한다.

- **채널:** 열린 채로 두는 draft PR "총괄 소통 채널"(이 파일을 더한 PR). 총괄 세션이 이 PR을 구독한다. 여기에 달린 댓글은 총괄을 바로 깨운다. 그래서 정기 확인 없이 처리된다.
- **Codex가 할 일**
  - 작업을 끝내면 자기 PR에 보고 댓글을 남긴다.
  - 같은 내용의 한 줄 알림도 이 채널 PR에 남긴다: `[Codex → Claude 총괄] <작업 이름> — <PR 링크> head <SHA>`
  - 질문도 이 채널 PR에 남긴다.
- **총괄이 할 일:** 알림을 받으면 그 PR을 구독한다. 그다음 독립 검수, CI 등록·캐시 판올림, 병합·배포를 한다. 회신은 `[Claude 총괄 → Codex]`로 시작하는 댓글을 그 PR에 남긴다.
- 이 PR은 병합하지 않는다. 채널을 끝낼 때만 닫는다.
- 작업 규칙은 [AGENTS.md](../../AGENTS.md)를 따른다. 작업자 금지 사항은 그대로다.
