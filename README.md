# 인생 해도 — Life Sounding Chart

시간·기간·깊이(행복)를 한 장의 측량도로 기록하는 **단일 HTML 인생 연표 에디터**.

**▶ 바로 쓰기: https://wonchance-art.github.io/life-haedo/**

## 특징
- **행복 곡선 중심** — −1~+1 척도, 같은 달 여러 기록은 월 평균으로 완만하게 (단조 3차 보간)
- **사건 = 곡선 위의 주석** — 점 옆 라벨, 호버 설명 카드, 행복 반영 여부 체크(해제 시 0선)
- **노션식 인페이지 편집** — 클릭 팝오버 · 더블클릭 추가(위=기간·아래=사건) · 2D 드래그(상하=행복·좌우=시기) · 막대 끝 리사이즈/중앙 이동 · 우클릭 메뉴 · ⌘Z undo/redo
- **시대(章)·기간 레인·항로 지도**(Leaflet) · 검색(⌘F) · 미니맵 스크러버 + 시간 훑기 재생
- **다중 문서** + **Supabase 온라인 DB 동기화**(☁ DB — URL·anon 키만 입력, 키는 localStorage에만 저장)
- 저장은 브라우저 로컬 우선(오프라인 안전), 서버 없이 파일 하나로 동작

## 시작
1. 페이지 열기 → 예시 해도가 보인다
2. `✚ 새 해도` → 이름·출생 연월 입력 → 자기 해도 시작
3. 캔버스 더블클릭·드래그로 기록

크레딧: 스크러버·검색 등 일부 UX 패턴은 [Timelines Studio](https://github.com/sreegjl/timelines)(GPL-3.0)에서 착안해 독자 구현.
