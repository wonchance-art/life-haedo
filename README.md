# 인생 연표

시간에 따른 행복도와 사건·기간·생각·장소를 한 화면에 기록하는 **개인 연표 에디터**.

**▶ 바로 쓰기: https://wonchance-art.github.io/life-haedo/**

## 특징
- **행복 곡선 중심** — −1~+1 척도, 같은 달 여러 기록은 월 평균으로 집계하고 곡선 강도를 선택
- **사건 = 곡선 위의 주석** — 점 옆 라벨, 호버 설명 카드, 행복 반영 여부 체크(해제 시 0선)
- **빠른 기록 추가** — `기록 추가`에서 사건·기간·생각 선택, 클릭 팝오버와 더블클릭 추가, 2D 드래그, ⌘Z 실행 취소
- **시대(章)·기간 레인·항로 지도**(Leaflet) · 검색(⌘F) · 미니맵 스크러버 + 시간 훑기 재생
- **분야와 기록량** — 노동·학습·여행·독서·사람 그래프, 월별 글 밀도, 생애 격자
- **다중 문서** + **Supabase 온라인 DB 동기화**(☁ DB — URL·anon 키만 입력, 키는 localStorage에만 저장)
- **PWA** — 브라우저 로컬 우선 저장, 오프라인 실행, SVG·PNG 내보내기

## 시작
1. 페이지를 열고 문서 메뉴에서 `＋ 새 문서` 선택
2. 이름과 출생 연월 입력
3. `＋ 기록 추가`에서 사건·기간·생각 선택
4. 연표의 점과 기간을 클릭하거나 드래그해 수정
