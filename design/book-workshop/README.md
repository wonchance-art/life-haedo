# 책 작업실 · 두 방향 비교 시안

2026-10-09: 비교 후 사용자가 **A · 원고 중심**을 선택했습니다. 이 폴더는 비교 당시 두 안을 보존하며, 실제 앱 적용은 별도 코드와 검증으로 진행합니다.

**A와 B 모두 미선택 비교 시안이다. 운영 디자인 변경은 승인되지 않았다.** [방향 계약](../../docs/design-review/book-design-reset.md)의 책 선택 → 전체 읽기 → 장 집필 → 읽던 문단 복귀를 비교한다. [운영 DESIGN.md](../../DESIGN.md)는 보존하며 `.impeccable/design.json`은 생성·갱신하지 않는다(현재 파일 없음). 이 문서는 시안의 관찰값이며 운영 디자인 규칙을 대체하지 않는다.

## 열기와 재생성

[독립 비교 HTML](../../docs/design-review/evidence/book-design-reset/comparison.html)을 브라우저에서 파일로 연다. 저장소 안에서는 [개발용 index.html](index.html)을 직접 열어도 된다. 최신 브라우저의 `structuredClone`, Blob 다운로드, CSS `dvh`를 사용한다. 폰트는 기기에 설치된 글꼴을 쓰므로 OS별 모양은 달라진다.

저장소 루트에서 아래 명령으로 독립 HTML을 다시 만든다. Node.js 표준 모듈만 쓰며 패키지 설치는 필요 없다.

```sh
node scripts/build-book-design-preview.mjs
```

[빌더](../../scripts/build-book-design-preview.mjs)는 `index.html`, `ui.css`, `ui.js`, `sample.js`, 기존 `assets/life/icons.js`를 하나의 HTML에 인라인한다. 출력 경로는 `docs/design-review/evidence/book-design-reset/comparison.html`이며 네트워크 연결을 막는 CSP를 포함한다. 원본 샘플을 재생성하는 명령은 아니다. 운영 빌드·Pages 허용 목록·서비스워커는 바꾸지 않는다.

- 상단 A/B로 같은 샘플의 두 구성을 전환한다. 상태 선택은 기본·가상 40권·빈 목록·불러오는 중·저장 실패를 보여 준다.
- 책 제목 또는 전체 읽기 → 장의 편집 아이콘 → 원고 수정 → **반영** → **읽던 곳으로** 순서로 비교한다. 반영 전 화면 이동은 막고 반영 버튼으로 안내한다. 문단 복귀는 세션의 문장과 위치를 사용하며 본문 변경 뒤에는 문단 ID를 대안으로 쓴다.
- 원문 보기를 열어 작성자 관계·작성일·보관 범위·이전 버전·현재 해석을 확인한다. 저장 실패 상태에서 입력 보존과 다시 시도를 확인한다.
- 파일 주소 뒤 `?direction=B&view=edit&chapter=1`로 B의 두 번째 장을 연다. `direction=A|B`, `view=list|edit|read`, `chapter=0..3`을 지원한다. `presentation=1`은 비교 도구와 샘플 안내를 숨기는 캡처용 설정이다.
- 비교 폭은 1440·820·390px을 사용한다. Tab 이동·포커스 표시·긴 한글 제목·원문 펼침도 살핀다. 화면 크기 모사는 실제 iPad/iPhone 검증과 구별한다.

## 색과 글자

기준 구현은 [ui.css](ui.css)다. A는 `:root`, B는 `body[data-direction=B]`의 재정의이며 파일 끝의 보정 규칙까지 적용한다.

| --- | --- | --- |
| `--ink` 본문 | `#262330` | `#253638` |
| `--subtle` 보조 글자 | `#6a6172` | `#56686b` |
| `--accent` 선택·주요 조작 | `#684477` | `#23685f` |
| `--wash` 옅은 조작면 | `#f4edf6` | `#e5f1ed` |
| `--line` 구분선 | `#e9e3eb` | `#dce5e3` |
| `--ground` 바깥 바탕·B 목차 | `#fbf9fc` | `#f2f6f5` |
| 본문 표면·상단 바 | `#fff` | `#fff` |
| 선택한 텍스트 배경 | `#e4cfee` | `#c4e3d8` |
| `--body-size` / 읽기 행간 | 19px / 1.95 | 17px / 1.9 |
| `--measure` 기본 원고 폭 | 680px | 650px |

공통 글꼴은 `"Apple SD Gothic Neo", "Noto Sans CJK KR", "Malgun Gothic", sans-serif`다. 외부 웹폰트는 없다. 장 제목은 700, 자간 `-.025em`; 버튼은 14px, 메타 정보는 12px, 출처 본문은 15px/1.9다. 한글은 `word-break:keep-all`과 `overflow-wrap:anywhere`를 함께 쓴다. B 집필 textarea의 행간은 데스크톱에서 공통값 1.95를 유지한다. 모바일은 두 안 모두 본문 17px/1.9, 집필 제목 27px, 읽기 장 제목 26px이다.

## 배치와 간격

| 구분 | A · 원고 중심 | B · 편집 작업실 |
| --- | --- | --- |
| 주요 구조 | 중앙 원고 한 열, 목차 버튼으로 펼침 | 집필·읽기에 왼쪽 고정 목차와 오른쪽 원고 |
| 외곽 최대 폭 | 1360px | 집필·읽기 1440px, 목록 1140px |
| 원고 열 | `min(680px, 100% - 48px)`, 위 40px / 아래 100px | `min(650px, 100% - 72px)`, 위 32px / 아래 100px |
| 목록 | 최대 880px, 기본 위 35px / 아래 96px | 최대 850px, 위 30px / 아래 96px |
| 상단 바 | 높이 76px, 좌우 42px | 높이 66px, 좌우 30px |
| 목차·원문 | 목차를 위에 펼침; 집필 원문은 제목 앞에 표시 | 목차 248px; 넓은 집필 화면의 원문은 240px 보조 열, 열 간격 40px |
| 제목 다음 간격 | 28px | 24px |

문단 아래는 `1.4em`, 다음 장은 위 여백 40px와 내부 여백 72px 및 1px 선으로 구분한다. 작은 조작 간격은 주로 8·12·16px, 출처 구획은 24px다. 버튼은 최소 높이 44px, 기본 안쪽 여백 9px 14px, 아이콘 조작은 44px 정사각형이며 기존 20px 도형을 재사용한다. 목록은 구분선으로 나누고 그림자 카드를 만들지 않는다. 버튼 모서리는 10px, 모드 전환과 해석 면은 12px다.

| CSS 경계 | 실제 변화 |
| --- | --- |
| `min-width:1100px` | A 첫 책을 본문과 230px 목차의 두 열로 배치, 간격 48px. 목록 위 여백 52px. 추가 가상 책은 한 열 유지. |
| `max-width:1050px` | B 목차 206px, 원고·목록 좌우 총 52px 여백. 집필 원문은 아래로 이동. 공통 책 제목 경로 폭은 180px로 제한. |
| `max-width:650px` | 두 안의 원고·목록 좌우 20px, 원고 위 20px / 아래 80px. 상단 바는 66px. B 고정 사이드바를 숨기고 네이티브 장 선택을 사용. |

B 모바일에서는 읽기의 장 선택, 집필의 장 선택·원문 버튼 행이 상단 바 아래 `top:66px`에 고정된다. 초기 방향 계약의 “목차 펼치기”는 현재 **장 선택 select**로 구현되어 있다. 읽기에서 여는 원문은 두 안 모두 해당 장 아래에 표시한다. 원문은 기본 접힘이며 목록에는 B 사이드바가 없다.

상단 바는 흰색 sticky 표면이다. 포커스는 강조색 3px 외곽선과 3px 간격을 쓰며 원고 입력은 얇은 왼쪽 표시를 사용한다. hover 전환은 배경색 140ms `ease-out`만 사용한다. `prefers-reduced-motion`에서는 전환을 끄고 `forced-colors`에서는 버튼 경계와 선택·포커스를 시스템 색으로 표시한다.

## 샘플 출처와 저장 범위

[sample.js](sample.js)는 기존 익명 [reader-book-backup.json](../../docs/design-review/evidence/book-edition/reader-book-backup.json)에서 책 1권·4개 장·출처 6개·원문 버전 7개를 그대로 추출한 고정 비교 자료다. 원본의 ID·본문·버전 연결·작성자 관계·보관 범위·해석을 유지한다. 샘플과 백업은 비교 기준으로 보존하며 시안 조작으로 수정하지 않는다. 작성자 미확인·타인 글·일부 보관·링크만 보관을 내 글 또는 전체 본문으로 바꾸지 않는다. 제외된 해석은 표시하지 않으며 원문과 내 해석은 별도 구획이다.

문서화 시점의 SHA-256:

```text
reader-book-backup.json  4af34eefa6f8b0cf418b2d08244a97b82c7a71e153d0bafe5f1f37413a1111df
sample.js               a4e38018ebcb1fba9a6d0ad9be3f6bbce10cc9297af1e7313bf9e41d56d008ef
```

[ui.js](ui.js)는 샘플 책을 `structuredClone`한 메모리 사본만 편집한다. 샘플 객체 자체를 `Object.freeze`한 구현은 아니므로 향후 변경도 원본을 수정하지 않는 계약을 지킨다. **반영은 현재 탭의 시안 사본에만 적용되며 새로고침하면 초기화된다.** 실패·불러오기·40권 목록은 검토용 모의 상태다. 같은 샘플 제목을 복제한 40권을 실제 책으로 세지 않는다.

**예시 원고 받기**는 반영된 책 제목·장 제목·장 원고만 Markdown 파일로 다운로드한다. 펼친 원문·출처 메타 정보·해석을 포함하는 제품 백업이나 운영 내보내기 형식이 아니다. 다운로드는 공개 게시·동기화가 아니다. 입력한 내용은 다운로드 파일에 포함될 수 있으므로 비교에는 익명 예시를 사용한다.

새 의존성, 실제 저장소, 인증, IndexedDB/localStorage, 동기화·공개 API, 운영 렌더링 연결을 추가하지 않는다. 독립 HTML의 통신 차단과 메모리 편집을 유지한다. 기존 제품의 책 보관·복원·PDF·정확 원문 복귀 기능 전체를 구현한 화면으로 평가하지 않는다.

## 선택 후 적용할 때

1. 사용자가 고른 방향과 적용할 화면 범위를 먼저 기록한다. A/B 비교 결과를 선택의 대리 근거로 삼거나 둘을 임의로 섞지 않는다.
2. [PRODUCT.md](../../PRODUCT.md)와 운영 [DESIGN.md](../../DESIGN.md)의 책·원문·해석·저장 계약을 다시 확인한다. 선택된 안의 배치와 필요한 토큰만 기존 공통 CSS·아이콘에 연결한다. 시안의 메모리 저장 코드를 운영 저장 구현으로 옮기지 않는다.
3. 선택되지 않은 안은 비교 이력으로 남긴다. 시안 전환 도구·모의 상태·샘플 데이터를 운영 화면에 승격하지 않는다. 책 화면의 선택을 앱 전체의 색·레이아웃 변경으로 확대하지 않는다.
4. 실제 저장 실패 뒤 입력 보존, 정확 버전 연결, 읽기 복귀, 기존 백업·내보내기 범위를 보존하면서 넓은 화면과 모바일·키보드·한글 입력을 확인한다. 실제 Apple 기기 확인과 브라우저 크기 모사를 별도로 보고한다.
5. 운영 적용이 승인되고 구현이 확정된 뒤에만 Impeccable document 절차로 `DESIGN.md`와 필요한 `.impeccable/design.json`을 갱신한다. 지금은 두 파일의 기존 상태를 보존한다.
